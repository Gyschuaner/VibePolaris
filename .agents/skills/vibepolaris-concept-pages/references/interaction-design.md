# 演示、视觉与代码接入

在设计首图、正文编排、互动演示或接入现有组件时阅读。以下是本站已确认的体验方向，尺寸、时长与场景数量根据内容决定。

## 让概念决定交互

| 参考页 | 首图的表达 | 主体演示的表达 | 可迁移的思路 |
| --- | --- | --- | --- |
| Harness | 模型、调度、工具之间的请求与反馈 | 服务修复对话，实际工具状态与验证分支 | 呈现多种职责怎样协作 |
| 工具调用 | 请求发出、实际结果返回 | 请求包在模型、Harness、文件工具间移动，授权决定是否执行 | 交接、路由、协议、请求响应 |
| 上下文 | 不同资料叠合成当前输入 | 读者选择纸片，材料移入输入区，移除后回答失效 | 选择、装配、容量、保留与排除 |
| 智能体循环 | 三次修正逐次出现 | 轮次、真实代码差异和检查结果并排展示 | 反馈、版本演变、重试和停止 |

这些是选择画面的方法，不是要求以后所有概念都用纸片或编辑器。一个队列可能适合排队与出队，一个布局概念可能适合拖动尺寸，一个缓存概念可能适合命中和回源分支。

### 开始写组件前的场景契约

用已有工作笔记记录：初始输入、可操作对象、动作触发、状态改变、可见证据、继续或停止条件、重置效果。只有演示确实涉及失败、权限或异步等待时才增加这些分支。

每个动作都应让读者看见机制变化。不要只有图标依次变色、下方说明换句子；也不要把每个首图都做成同一条曲线上的三个节点。

针对多页的检查：遮住标题和标签，是否仍能从空间组织、对象运动和交互方式看出差异？如果完全一样，重新选机制。复用播放、暂停、聚焦与状态管理没问题；不必为了“不同”重写公共能力。

## 版式与视觉

- 延续项目的背景、主题色、字体与留白，使用现有 CSS 变量；验证现有主题切换，不固定写死截图颜色。
- 正文、演示及其展开状态共享阅读宽度；代码长行、错误文本、控件和局部星图不能把文章撑宽。
- 按解释任务安排版面：连续讲解用正文，职责差异用对照，具体执行用代码和结果，关键判断可用大字引文。变化为理解服务，不按预定配额塞齐所有模块。
- 首屏标题和小型机制图要有主次。桌面可以错位或并排，窄屏恢复自然阅读顺序，不能通过缩小整张桌面图解决手机排版。
- 品牌星星用于标题、入口和星图节点；一般职责使用项目已有语义图标。避免星星充当文件、工具、检查等所有角色。
- 控制区通过间距和对齐分组，避免装饰性的多重横线、边框套边框、重复编号及状态脚注。
- 删除无用小字时保留真实信息：必要的角色、参数、输入、结果和操作仍应可见。无障碍名称可保留，不必为了极简去掉读屏信息。

## 动效顺序与生命周期

**状态决定动画，动画不伪造状态。** 场景通常可以复用现有 React 状态与 CSS transition/keyframes，无须先引入动画依赖。

- 文本流式生成 → 完整请求 → 校验 → 执行 → 实际返回 → 后续回答。依赖前一步完成的内容由完成事件推进，不用互不相关的定时器抢先显示工具。
- 执行中保持等待态。结果尚未产生时，不显示后续日志、检查结论或“已完成”；格式校验通过也不等于操作成功。
- 进入和退出都保留过渡。退出时过早卸载 DOM 会吞掉淡出；可复用持久层、网格高度过渡或现有披露组件。隐藏层应不可聚焦，并正确设置 `inert`、`aria-hidden` 或原生语义。
- 输入材料、场景或轮数变化时，使旧回答和旧进度失效；取消旧定时器、未完成的流式过程与动画回调，避免新场景被旧回调覆盖。
- 有限自动演示播放一轮后停住，支持暂停、推进和重播。离开可见区域或进入后台暂停，组件卸载清理监听和计时器。
- 动画终点必须稳定、可读。首图一遍播放完成后保留关键关系，不持续漂动干扰正文。
- 尊重 `prefers-reduced-motion`：关闭位移、惯性和装饰循环，同时保留所有信息与直接操作；不能仅关闭动画后把元素永久留在透明起点。
- 桌面、手机与键盘使用同一份状态语义。读者快速连点、切换、重置时不能看到旧结果闪回。

性能优先从更新范围着手：移动对象尽量更新 transform/opacity，避免用每帧 React 全页重渲染；不在所有章节添加永久帧循环。已有星图和鼠标效果由公共实现管理，文章不再复制一份。

## 已确认的基础交互

### 对话演示

用户消息在右侧，模型回复在左侧；工具调用归属于发起它的模型轮次。模型与 Harness 模式沿用一致的聊天语义，但清楚区分建议和真实执行。

若有“继续问模型”输入，应能输入、发送和追加消息；固定教学回答可以保留，但在适当位置交代演示性质。固定回答不得谎称读取了真实文件或针对任意输入完成了分析。不在每轮重复加入服务器、教学和免责声明脚注。

### 阅读目录与补充内容

目录名称对应正文实际标题，不使用另一套缩写或从无关 Markdown 标题生成。当前章节随正文阅读更新，活动项自动保持可见；保留手动浏览目录的能力，不让读者必须单独拖动滚动条才能找到当前项，也不抢夺正文滚动。不显示额外“本页”标题。

补充区域保留原生键盘或等价语义；开合都平滑，当前目标不被固定页头遮住。为已有外链、书签和参考文献保留锚点；必要时用别名锚点兼容。

### 术语卡片与参考资料

卡片由点击或键盘操作打开，短释义在旁边显示，不覆盖触发词；窄屏限制在视口内，支持关闭并恢复合理焦点。点击书目三角展开引用摘录，不能改回 hover 展开。具体引用数据约定见 [正文与资料研究](editorial.md)。

### 局部星图

中心是当前词条，周围为实际关联词条；自然错落，避免线性学习路径或刻板等距辐射。复用 `ConceptGraph` 的 inline 模式，不新做静态假星图。

沿用现有行为：悬停或聚焦能读名字，点击显示选中词条的关系与阅读入口，跳转保持站点流星动效；只展示相关连线，不常驻满屏装饰线。普通滚轮与空白处触摸用于读文章，缩放不能劫持正文；拖动和点击要区分。修改了星图才验证这些行为，不把它当成每次文案编辑的全站测试。

### 这四页暴露过的具体问题

- 曲线、对象位置与步骤完全相同，只换名词：改核心场景，不能只补动画时间差。
- 图多到正文失去解释：恢复可独立阅读的文章，再删真正重复的部分。
- 工具先于流式文字出现：梳理阶段依赖与取消逻辑，不靠增加延时碰运气。
- 选完材料后仍显示旧回答：输入变化时立即使其失效，并保留退出过渡。
- `svg path` 一类过宽选择器破坏 Phosphor 图标：轨迹使用专门类或明确子级，不把图标路径当连线。
- 中心名称硬编码为 Harness：从当前词条数据派生。
- 纸片遮住重要文字、窄侧栏挤出孤字：检查终态、中间态和实际标题长度，调整重叠和列宽，不只看预设短标签。
- 引用收起和滚动同时开始导致落点偏移：等待相关高度过渡稳定后再定位。
