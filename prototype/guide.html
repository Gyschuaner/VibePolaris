《AI 模型 / 编程工具怎么选》

更新于 2026-08-28·超过 90 天本页会提示可能过时·本页为人工整理，非 AI 生成

先说结论

不会写代码、想把想法做成能用的东西：生成式建站工具起步（Lovable / v0 / Bolt 任一），遇到坎再把具体报错丢给对话模型问。

有一点基础、想认真做产品：AI 编辑器（Cursor）+ 强推理模型做主力，省钱场景切 DeepSeek。

是开发者、要控盘大项目：终端系 Agent（Codex / Claude Code）接进现有仓库，模型按任务混用。

先问自己三个问题

  • 写不写代码？完全不写 → 生成式建站；看得懂报错 → AI 编辑器；直接写 → 终端 Agent。
  • 预算多少？免费额度试水，认真做每月 ¥150~350 是常见区间；纯按量用 API 的话 DeepSeek 一档最省。
  • 做多复杂？单页小工具随便选；要登录、数据库、支付的正式产品，优先选能看清代码、能本地跑的方案。

对话模型：怎么选脑子

候选定位擅长代价
Claude长任务与代码主力大改动、遵循复杂指令、写代码稳价格中高，高峰限流
GPT 系生态最全的通用助手多模态、插件生态、语音图像订阅项目多、略杂
DeepSeek极致性价比推理能力强、API 便宜、中文顺长上下文体验一般、偶发排队
Gemini长上下文与免费额度读超长文档、免费层大方代码风格偶尔飘

编程工具：怎么选工位

候选定位适合谁代价
CursorAI 原生代码编辑器半专业与专业开发者订阅制，需看懂代码
Codex / Claude Code终端里的编程 Agent开发者，接现有仓库干活命令行门槛，按量计费
Lovable / Bolt说一句话出整个应用不写代码的创作者复杂逻辑会撞墙，迁移要看导出
v0生成界面组件起家要好看前端页面的人偏 UI，后端要另接

向 AI 这样说

选型定了之后，第一句话就把约束说满，复制改改就能用：

【我要做】一个 ______（一句话产品） 【技术约束】我用 ______（如 Lovable / Cursor），不会写代码，要求不装本地环境 【功能范围】第一版只要 ______、______、______ 三个功能，其余都不要 【交付标准】做完告诉我：怎么发布上线、怎么改文案、出问题把报错原样贴给谁
