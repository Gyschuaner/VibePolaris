# VibePolaris

VibePolaris（Vibe 指北）是面向 Vibe Coder 的术语词典与概念星图。

## 本地开发

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。旧版 `prototype/` 仅作为视觉评审基线，不再承载正式页面。

内部受邀助手“小北”的百炼配置、邀请码和积分持久化说明见 [VBP-047 开发与运行说明](docs/development/VBP-047-xiaobei.md)。公开页面无需模型配置即可阅读。

## 验证与构建

```bash
npm run check
npm run start
```

- `npm run dev`：组件化开发与热更新。
- `npm run build`：校验结构化内容并生成优化后的生产构建。
- `npm run start`：运行生产构建。
- `npm run check`：依次执行 ESLint、TypeScript、测试与生产构建。

基础术语位于 `content/zh/terms.json`，扩展词库按领域拆分在 `content/zh/term-batches/`；分类位于 `content/taxonomy.json`，工具位于 `content/zh/tools.json`。构建时由 Zod 校验字段、分类、动画步骤、关联词条和 slug 唯一性。

首页 `/` 从词库的 `relatedSlugs` 自动生成概念星图；`/?term=<slug>` 可定位某个概念。详情页相关词条与星图共用这些关系，不按分类补充未声明的链接。每个词条可声明 2–8 个关联，星图合并双向重复连线，并显示反向关联。

星图使用 [D3 Force](https://d3js.org/d3-force) 模拟连线牵引、节点排斥与碰撞；`lib/term-graph.ts` 共用同一套力参数生成初始布局并驱动页面互动。拖动节点会带动邻居，释放后逐渐稳定；鼠标经过时轻微扰动附近星星，指向星星时停止鼠标扰动；超过180个节点的大图在缩放低于0.75时停用鼠标扰动，并直接使用构建时已稳定的入场布局，节点拖动仍保留邻居牵引。默认隐藏名字，悬停或键盘聚焦立即展示当前词条；点击后固定显示当前及相邻词条的名字和连线，其他名字随放大渐显。标签保持屏幕字号，远景悬停也可读。拖动和缩放复用星点及连线子树，只更新外层变换与缩放样式；D3 直接更新发生变化的节点 transform 与可见连线端点，不触发 React 整图重绘。悬停只更新前后两个星点，并跟随实际指针移动，不随节点运动反复切换，也不改变全图明暗。页面隐藏时暂停模拟，减少动态偏好下保留直接拖动并停用惯性和鼠标扰动。拖动不改写词库，新增词条或关系重新构建即可同步。

交互参考 [Quartz Graph](https://github.com/quartz-community/graph) 的力学图谱思路；保留本站 DOM 星星、键盘操作及词条流星跳转，只引入 `d3-force`（ISC），未复制 Quartz/PixiJS 渲染实现。

桌面鼠标保留系统指针和轻量主题色光晕，可点击内容悬停时收拢。按住主键拖动时，使用已确认的 A「水面包络」：最近 840ms 的轨迹融合为一条连续水痕，尾部渐细，松开后整片轮廓在 780ms 内舒展消散。选字时仍有水痕，但降至常规强度的28%并隐藏光晕；标注工具条等松开后出现，点击工具条不叠加水痕。空白拖动保持原强度，输入框与星图避让；滚动、离开窗口时清理效果，触摸与减少动态偏好不启用。固定一个 SVG 路径，轨迹采样按帧合并，并限制历史距离与点数，不触发 React 渲染或空闲帧循环。设计与接入记录见 [VBP-009 连续包络线](docs/design/VBP-009-envelope/README.md)。

Harness 文章以修服务任务贯穿五段阅读：演示、分工、上下文、验证边界、关联探索。对话默认显示当前一轮，可展开完整记录；原理动画可逐步操作、暂停和重播。离开可阅读区域或隐藏页面后停止自动播放，减少动态偏好下直接展示关键状态。旧章节与引用锚点保留，参考资料可打开折叠正文后跳转。

原理演示使用语义图标区分模型、调度、工具和验证，控制区以留白分组。补充内容保留原生 `details` 键盘操作，通过 CSS 开合过渡、分层渐入和容量条动画呈现；减少动态偏好下关闭动画。品牌星星用于标题和概念星图。

Harness 的职责、请求与执行的区别、结果回传、上下文和停止条件保留为常驻正文，不要求读者播放动画或展开补充项才能理解；动画前交代输入和背景，动画后解释执行结果。词义与其他案例仍按需展开。

Harness 首屏用模型、调度、文件和终端图标概览运行关系：首次进入可见区域播放一轮读日志的往返，悬停或键盘聚焦显示对应路径与解释，点击进入相关正文。离开视口或切到后台停止播放，减少动态偏好下静态显示；手机端图形排列在标题下方。

Harness 正文中的局部星图复用 `ConceptGraph` 的 inline 模式：仅加载中心词条及其 8 个关联，中心固定；点击显示关联与紧凑阅读入口，保留流星跳转。局部图不改写文章 URL；普通滚轮和空白区域纵向触摸用于阅读正文，可用缩放按钮或 Ctrl/触控板捏合调整星图。

工具调用、上下文、智能体循环使用同一阅读方式，但各自设计演示：请求与执行分离、选择本轮材料、根据反馈推进并停止。`ConceptArticle` 复用目录、术语卡片、引用与局部星图，`ConceptLessons` 保存预设教学场景；参考文献和对应段落在 `lib/concept-article-sources.ts` 维护。新增文章先写完整正文和来源，再设计可操作的过程，不依赖播放动画才能读懂。结果在对应操作完成后揭示，开合与步骤切换保留过渡，并尊重减少动态效果的偏好。 首图由 `ConceptHero` 分别表现请求往返、资料叠合和三次修正，只在可见时播放一遍，可手动重播。工具演示移动请求与返回包；上下文直接把可选材料移入、移出输入区；循环并排展示轮次、代码修改和实际检查，不再套用相同的图标连线。大屏正文按内容采用侧栏标题、内外资料对照与重点引文，手机端恢复顺序阅读。

首页是统一概念入口：领域切换只聚焦和突出对应星群，保留真实跨领域关系；`/?cat=<分类>` 可定位领域，`/?q=<关键词>` 打开搜索。旧 `/terms` 与 `/graph` 使用永久重定向进入首页并保留查询参数，`/terms/<slug>` 详情地址不变。导航与站点地图只收录统一入口。

词条和 HTML、CSS、JavaScript 教程支持划线和批注，桌面批注对齐原文，手机使用底部面板。点击头像进入“我的主页” `/me`，其中的“我的笔记”可搜索、随手记、删除撤销及导入导出 JSON 备份。未登录时保存到当前浏览器的 IndexedDB；登录后使用账号独立的笔记库，可手动同步或开启笔记自动云同步。旧游客笔记由用户明确选择合并，原件保留、重复内容去重、并发冲突保留两个版本。实现见 [VBP-114 阅读笔记与账号同步](docs/development/VBP-114-reading-notes-sync.md)，原交互见 [VBP-020 本地笔记](docs/design/VBP-020-local-notes/README.md)。

六个板块的全站开关集中在 `content/site-modules.json`：`graph` 星图、`canvas` 知识画布、`library` 组件库、`news` 新闻、`notes` 我的笔记、`about` 关于。修改布尔值并重新构建部署后生效。默认开启星图、画布、组件库、笔记，隐藏新闻和关于；关闭板块的导航、页脚和独立页面入口同步隐藏，旧地址临时跳到可用首页，全部关闭时回到 `/me`。个人主页和设置保持可访问，关闭开关不会删除数据。说明及验证见 [VBP-119 板块开关与个人主页](docs/development/VBP-119-section-visibility.md)。

组件库 `/library` 提供组件、样式、素材和 300 个动画，支持分类、类型与名称筛选。动画按 13 个小分类收进卡片，左侧完整预览、右侧可滚动的小预览，点击后以 700ms 平移交换位置。默认显示真实静帧，仅当前悬停或键盘聚焦项以 0.6 倍速播放。详情只展示当前条目的实际预览、源码或下载、AI 描述及来源许可；动画支持重播、暂停、倍速和 React / HTML+CSS 导出。动画 CSS 按需加载，离屏或后台暂停，减少动态偏好下默认静止。目录与来源版本见 [VBP-121 动画库](docs/development/VBP-121-animation-library.md)，浏览交互与验收见 [VBP-122 分类卡片](docs/development/VBP-122-category-motion-cards.md)。

导航中的“知识画布”进入 `/canvas`，支持笔记、链接、图片和待办节点。空白处右键或“新建节点”选择类型，双击空白处直接新建笔记；节点右键和卡片“…”可打开 Markdown、编辑标题摘要、连接、复制、导出或删除，删除后可撤销。标题和摘要在简述卡片中直接编辑并自动保存，未手动填写的旧笔记仍从正文提取。图片支持 5 MB 内的 PNG/JPEG/GIF/WebP/AVIF 或图片网址；待办在卡片添加、勾选和删除。可任意拖动节点、移动缩放画布；触屏单指拖动、双指缩放与平移，抬起一指后不会继续拖动节点。可拖动圆点或点选两个节点连线，连线绕开文字和图片。点击节点先看简述，再打开全文阅读；编辑时左侧 Markdown、右侧实时预览，中间分隔条可拖动或用方向键调整，双击恢复均分，手机端使用编辑／预览切换，保持正文、光标与撤销；平板宽度充足时保留双栏，窄分屏自动切换单栏。日期仍只在简述底部弱化显示。

支持多份 UTF-8 `.md` / `.markdown` 导入（每份最多 10 MB）。复制与导出保留正文，并将手动标题、摘要、节点类型写入不影响普通 Markdown 阅读的开头注释；本地图片嵌在正文中，重新导入可恢复。历史未编辑元数据的普通笔记仍按原文导出。Markdown 不包含画布布局和连线。

游客画布、位置和连线使用独立的本地 IndexedDB 自动保存，首次为空白画布。不同浏览器、域名或端口不共享游客数据；清除网站数据前请导出需要的 `.md`。可选的用户名密码账号支持私有云画布：登录本身不上传游客内容，用户主动保存到账号后，可开启或关闭「自动同步到云端」，也可手动同步。不同浏览器的游客画布分别保存，保留本地原件；云端同处修改保留冲突副本，独立修改自动合并。关闭同步时修改保留在当前浏览器的账号缓存中，重新开启再核对云端版本。画布草稿和文章的划线、旁注分别保存在所属节点，随画布同步；全站“我的笔记”使用独立的同步开关。账号隔离、数据格式和验证见 [VBP-101 账号与同步](docs/development/VBP-101-account-sync.md)，原画布操作见 [VBP-095 自由画布](docs/design/VBP-095-free-canvas/README.md)。

画布 Markdown 编辑时停顿约 3 秒，光标后出现淡灰快捷键提示。按 Command/Ctrl+Enter 或点提示主动请求一次小北补全，Tab 接受、Escape 放弃；接受前不写入正文，接受后可撤销。停顿本身不调用模型。游客沿用小北邀请码；登录后可将邀请码绑定账号一次，在不同设备和全站入口共用授权与原有积分账本。首次调用说明会向小北发送本笔记标题、前文提纲及最多 6000 字符的光标前文；补全接口不另外持久化正文或生成历史，云画布按用户选择同步。`XIAOBEI_COMPLETION_CHARGE_ENABLED=false` 默认关闭扣费，真实 Token 与原价积分仍计量，预占和实际扣分为 0；聊天计费不变。详见 [VBP-100 补全接入](docs/development/VBP-100-canvas-completion.md)。

记忆、上下文窗口、提示词、执行沙箱在 `ExtendedConceptPages` 中扩展：分别使用跨会话存取、容量尺、任务稿编辑、空间访问边界。`ExtendedConceptHeroes` 提供独立首图，复用 `ConceptHero` 的可见性与重播控制；`ExtendedConceptLessons` 保存本地状态，`lib/extended-concept-sources.ts` 维护来源与引用锚点。窗口的 100 格为示意配额；所有示例均不调用模型、读写用户文件或连接真实 MCP 服务器。

MCP 使用 `McpTermPage` 与 `McpLab`：以图书馆查询解释能力发现、请求和结果往返，切换两个应用展示同一服务说明的复用。首图与正文演示均有限播放；正文支持暂停、单步、重播，离屏停止，断开不清除已取得的历史。

桌面阅读页的目录／批注侧栏可收起为小按钮；正文阅读列宽度固定，侧栏仅在右侧滑入淡出，开合不挤压正文或改变换行。收起偏好保存在当前浏览器，写批注或点击高亮会展开侧栏。选型指南与工具模块暂时下线，站内入口及站点地图已移除，旧 `/guides`、`/tools` 地址临时跳回首页；HTML、CSS、JavaScript 深度教程继续从词条进入。

手机主导航按开放板块自动排布，默认提供星图、画布、我的三个带文字入口；“我的笔记”从个人主页打开。阅读页从“目录与笔记”打开面板，大屏沿用可收起的侧栏。实现与对照稿见 [VBP-116 移动适配](docs/design/mobile-reading-editor/README.md)。
