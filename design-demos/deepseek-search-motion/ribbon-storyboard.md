# C · 文字入稿

采用编辑排字的思路：把正文变成一条真实可读的文字带，先从来源中揭起，再拉直排入上下文。固定机位使读者可以追踪同一段内容。只显示通用信息对象，无具名产品 UI 或 Logo。

1000×560，8.4 秒，30fps 验收基准。背景是站点纸色，文字带为苔绿墨色。开始预览停在 4.8 秒；播放从开头运行一次，结束停留。

交互：播放、暂停与重播；时间范围输入可定位关键状态，标签为“动画位置”，没有步骤或编号。减少动态时直接呈现正文进入工作区的稳定终态。模型请求与框架执行边界由必要角色标签表示。机制样例不进行真实联网。
