# SignalScenes · 动作约定

组件：`components/news-motion/SignalScenes.tsx`。只返回 SVG `<g>`，位置和显隐完全来自 `progress`，使用传入的真实舞台尺寸；640px 以下分别重排。主文本 16px；不读取或显示 `result`，不自行计时、请求网络或访问 DOM。父组件统一处理播放、回退、减少动态和结果。

| scene | 约定动作与选用边界 |
|---|---|
| lens | 读头扫过一页来源文档，`items` 作为同一份正文逐行移入 `target` 工作区；`subject` 是文档、`actor` 是取回或提取的执行者，适合正文抽取、观察转文字。 |
| router | 单次输入只进入一个选中出口，其他 `items` 始终是候选项；目标直接匹配某个选项时使用该项，否则以首项作示意，适合有类型的分类，不把一次选择画成广播或暗示准确率。 |
| loom | 多根带 `items` 标签的输入线被梭子交错编成同一片材料；`subject` 是融合机制、`target` 是联合表示，适合有实际融合过程的多模态输入。 |
| ensemble | 周围各份 `items` 工作产物按指挥棒节奏进入中央共享稿；`actor` 是协调者，适合多个智能体各自产出后协作，不把协作画成已消除错误。 |
| patch | 一块写有真实变更项的补丁对准文件缺口落位，接缝逐段闭合；`items` 是具体改动、`subject` 是补丁能力，适合代码修复或局部更新，不编造代码内容或测试通过。 |
| footprint | 信息对象沿路径移动，每到一处留下与 `items` 对应的可见记录；适合活动产生的数据足迹、审计记录或使用记录，不把未证实的采集范围画成事实。 |
| border | 对象先抵达分域线，再通过有执行者标识的有限开口交接；`boundary` 写明权限或人工前提，仅用于稿件已证实的交接范围，不表示自动获批。 |
| camera | 至少一个对象起初只有部分入镜，先显示 `action` 提示，再平移同一来源补齐该对象；适合依赖用户调取景的视觉观察，不用缩框代替补拍，也不暗示完整无死角或准确率。 |
| canvas | 笔尖只在选中区域内留下笔迹，画布其他对象保持原位；`items` 是仍在画布上的真实组成，适合局部编辑与空间操作，不替代图像质量实证。 |
| depth | 原本重叠的层面沿深度展开，注册轴上的探针依次穿过各层；`items` 是真实层、空间或表示，适合分层与三维关系，几何距离不表示性能差异。 |
| circuit | 一枚输入沿芯片线路进入寄存位置，再向出口传递，边缘功能脚随过程锁存；`items` 是真实芯片模块或输入类型，适合硬件数据路径，不使用虚构吞吐或速度。 |
| bridge | 中间接合件先移到相对接口，插针吻合后对象才通过；`subject` 是兼容或连接能力，`boundary` 保留接口范围，不表示两端能力全部开放。 |

`source` 和 `target` 是实际来源与接收位置，不写成阶段编号。`actor` 只有执行或责任角色；`items` 保持 2–4 项短对象名，不能改写成说明步骤。新闻作者可从全部 32 种 scene 中择合适机制，不要求复用本文件的某一场景。

已完成 TypeScript/TSX 语法解析。真实浏览器画面和编译由父代理统一检查，本文不冒充截图验收记录。
