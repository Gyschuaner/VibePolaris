# VBP-098 · 全文过渡动效预览

本轮交付是供用户比较的三个可点击 HTML 初稿，正式画布接入须等待用户选择。用户原话：「你可以做三个动画给我选择一下看看」。三个版本使用相同的卡片、标题、示意 Markdown 正文、画布布局、尺寸与品牌色，只有运动方式不同。这里的示意笔记不读取或修改真实笔记。用户已提供截图，现有产品代码提供完整品牌和布局依据，无须额外素材或账号。

目标是在知识画布中，点击「打开全文」以后，能感受到从当前节点进入阅读，而不是在两个页面之间突然跳转。预览同时演示打开与返回；返回后卡片仍在原位。可在页面顶部切换 A、B、C，使用慢放观察中间状态，也可回到起点重播。页面不自动循环，不加音效，不加入新的产品功能。输出为独立 HTML，系统中文字体与品牌原有排印一致，适配桌面和窄窗口；主验收尺寸 1280×900，窄屏 390×844。演示区占满顶部比较控件以外的空间，不给画布再套一个装饰性浏览器框。

视觉基于用户截图的 pearl 背景：#EEF0EE，卡片 #F7F8F6，正文 #171A15，弱文字 #686E64，边线 #D2D7D2；交互色沿用截图的赭金色。保留圆点、选中标题底色、类型标记、可读的摘要、打开入口与弱日期。全文为真实 HTML 排版的示意 Markdown，标题、段落、小标题和引用共同体现从摘要到正文的层次。原型的标题与正文一致仅用于比较动效，正式接入不能假定节点元数据标题必然等于 Markdown 的一级标题。

三个方向分别回答三种空间关系：A「卡片展开」把浮动简述的纸面延伸成全文纸面；B「聚焦推近」让视线沿当前节点进入阅读；C「纸张铺开」让独立全文页从下方向上覆盖画布。三者初始和最终状态完全一致，禁止通过更换颜色、布局或文章内容制造差异。常速持续 340、380、360 毫秒，慢放为原速四分之一，采用缓出曲线；所有正文在运动后半段进入，避免短暂空白。系统减少动态偏好下直接切换可读状态。

轻量分镜如下。画布为后景，卡片为中景，全文为前景；只让本次过渡相关的主角运动。1280×900 下以画布区约 40% 横坐标的选中卡片作为焦点，不增加装饰图、粒子或大段说明。动态原型采用普通 HTML 与 Web Animations，符合交互演示的后端选型；无新依赖、无自动播放计时器。正式接入前还需处理真实路由、滚动位置、标题不一致、编辑状态、焦点恢复及中断，本轮只验证可比较的视觉方向。

## 动画模块约定

各 motion-*.js 只定义 `window.motion = (ctx) => { ... }`。ctx 包含 stage、canvas、card、reader、bar、title、body、ghost、ghostTitle、duration、rect、animate。rect.card / rect.fromTitle / rect.toTitle 均为相对 stage 的 {x,y,width,height}；rect.width/height 为演示区尺寸。animate(element,keyframes,options) 创建并收集已暂停、fill both 的动画，默认 duration 为本版本时长；可在 options 中覆盖 easing、duration、delay。模块调用 animate 即可，不自行播放、添加事件、修改 hidden 或移除 DOM。公共控制器按同一组动画正向播放或从终点反向播放，完成后统一复原；ghost 与 ghostTitle 为可设置初始样式的绝对定位临时层，parent 统一清理。A 可用纸面与标题层，B/C 不需要时保持 opacity:0。禁止修改公用文件。
