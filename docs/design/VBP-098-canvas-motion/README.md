# VBP-098 · 卡片进入全文的三种过渡

当前阶段：用户已选择 A，要求整体增加 0.2 秒；A 更新为 540ms，并接入正式 `/canvas`。研发需求为 VBP-098，负责人顾毅盛；确认原话见 [direction-approved.md](direction-approved.md)。

## 体验

在本目录运行 `python3 -m http.server 3002 --bind 127.0.0.1`，打开 <http://127.0.0.1:3002/>。也可直接用浏览器打开 `index.html`。三个 HTML 均内嵌品牌图片、脚本与样式，切换链接指向同目录的另两版；不需要 npm 或外网。

- A：[卡片展开](a-expand.html)，540ms。纸面从卡片原位延伸到全文，标题连续移动；正文后半段淡入。
- B：[聚焦推近](b-focus.html)，380ms。视线朝卡片标题推近，画布放大，全文接入并稳定。
- C：[纸张铺开](c-sheet.html)，360ms。前景全文纸面由下向上覆盖画布，标题提前进入，正文随后浮现。

点击「打开全文」播放；「返回画布」反向播放；「慢放」为 1/4 速度；「回到起点」或全文中的 Escape 可返回画布。各版使用同一组示意内容与起止布局，切换只改变动效。预览不读取 IndexedDB、剪贴板或用户笔记，无网络字体和新增依赖。

## 维护

公共页面为 `page.template`、`preview.css` 和 `controller.js`，三个动效分别为 `motion-a.js`、`motion-b.js`、`motion-c.js`。修改后运行 `node build.mjs` 重建四个独立 HTML。构建包含占位符、独立脚本与三方向入口的断言检查。

动画均使用浏览器 Web Animations API；打开和返回复用同一组关键帧，不使用链式计时器。过渡期间锁定临时操作并设置 inert，结束后清理临时层、恢复正确焦点；缩放窗口时结束至目标状态。系统减少动态偏好下直接显示目标页面。

正式接入使用浏览器 View Transition，从真实卡片边界过渡到全文，打开和返回均为 540ms。路由完成后开始动画，超时、中断与窗口变化会结束过渡；不支持该接口或系统要求减少动态时直接导航。节点标题与 Markdown 标题相同且在视口内时共享标题，否则分别淡入淡出，保留独立元数据和原始正文。
