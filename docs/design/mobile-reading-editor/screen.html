Harness

模型负责想下一步。Harness 把这一步变成真正执行的工作。

模型⇄Harness⇄工具

谁在思考，谁在动手？

当你让智能体修复一个报错，模型会决定先看日志。但真正打开文件、运行命令、把结果交回来的，是围绕模型搭建的执行环境。

你可以把它理解成一套工作台：有哪些工具可以用，哪些操作需要确认，以及什么时候继续或停止，都由它来组织。

# 我的 Harness 笔记

模型负责想下一步，Harness 负责
让这一步真正执行。

## 我理解的三个部分

- 模型：决定下一步
- 工具：执行具体动作
- Harness：把过程组织起来

> 执行结果还会回到模型的上下文。
