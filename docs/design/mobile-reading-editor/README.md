# VBP-116 手机和平板适配

用户于 2026-10-22 确认先制作导航、阅读页和 Markdown 编辑器的手机／平板对照稿，再实现并上线。范围是现有产品的响应式适配，继续使用现有纸色、主题、星标、字体和数据逻辑。

[可交互对照稿](comparison.html)包含三个视图，可切换导航、阅读和编辑；阅读稿可打开目录面板，手机编辑稿可切换预览。稿中的正文和星图是用于说明布局的示例，正式实现保留原有页面内容与演示。

| 界面 | 手机 | 平板 |
| --- | --- | --- |
| 导航 | 普通浏览页底部保留星图、画布、新闻、笔记；主题、账号、更多在顶部，更多包含设置和关于。 | 768px 起使用带文字的顶部导航，次级入口收进更多；桌面导航保持原样。 |
| 阅读 | 正文前不再排列重复工具。底部“目录与笔记”打开原生弹窗，目录纵向排列，选择章节后关闭。 | 1100px 以下使用有宽度上限的面板；更宽屏幕沿用可收起的目录／批注侧栏。 |
| Markdown | 768px 以下默认完整编辑区，编辑／预览切换保持同一个输入框、正文、光标和撤销记录。保存状态可见。 | 宽度足够使用双栏，分隔条保留拖动与键盘调整，限制每栏最小宽度约 360px。 |

常用按钮触区至少 44px，输入字号 16px，底栏与面板处理安全区。编辑器跟随可视视口高度，保留用户页面缩放。HTML、CSS、JavaScript 教程共用目录组件一并受益；不改课程正文、新闻列表、画布手势或后端数据结构。
