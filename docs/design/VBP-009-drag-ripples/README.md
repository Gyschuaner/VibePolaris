# VBP-009 连续拖动水波

2026-09-21，用户反馈按住鼠标拖动时水波消失，希望像手指划过水面一样连续激发涟漪。原实现超过6px拖动或出现文字选区时会取消唯一的动画，导致突然中断。

现在在有效区域按住鼠标主键移动时，光晕跟随，沿途产生独立水波；每一道波纹在650ms内扩散淡出，松开停止发射并保留余韵。静止按住不发射。文字选择不受阻止；输入框、星图的原生操作区域、触摸及减少动态偏好沿用避让规则。离开窗口、取消操作及切换动态偏好会清理反馈。

复用原样式和 Web Animations API，没有新增依赖。固定16个波纹节点，拖动生成间隔至少45ms、移动至少8px，避免重复抖动和无界堆积。移动不触发React状态更新，没有空闲发射定时器或持续帧循环。

## 限定验证

- `npm run build`通过，TypeScript与49页生成正常。
- 真实浏览器主键拖动空白时，沿途出现多个不同坐标水波；松开后仍有3道可见，随后全部归零，节点始终16个。
- 拖动正文选字保留原生蓝色选区，松开后光晕隐藏，仍有3道水波继续消散。[选字与水波证据](selection-waves.png)。
- 普通单击产生1道涟漪；笔记搜索框可正常聚焦输入，点击输入不增加波纹坐标，光晕隐藏。控制台无相关error/warn。
- 未扩展兼容矩阵、触摸设备、减少动态偏好和星图回归；这些原有分支未改动。无新增存储行为，不改动用户笔记。
