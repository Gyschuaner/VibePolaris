# 全量词条首图运动设计

关联 DP：VBP-012，研发任务 `192987cf-72c9-4461-8c85-d3ffb7a823d2`。

范围为373个公开词条的标题区。首图只保留对象、少量标签与连续运动；不使用编号、步骤导航、说明底栏、卡片底板。复杂教学过程仍在正文。每幅图的最大尺寸为280×140，手机端240×120；一次播放后停在有意义的状态，可暂停和重播，离屏与后台暂停，减少动态时显示终态。

先逐条确定下列机制，再实现相应构图与运动。共享播放能力和图形原语，运动按概念决定。
