已实际完成：默认星图 → MCP 聚焦 → 切换上下文 → Escape 复位 → 切换前端分类 → 组件聚焦 → 查看完整词条。使用电脑端 1440×1024 视口连续捕捉中间帧并查看关键帧。开发环境首次编译使跨页总等待时间不具有生产性能代表性，本轮不声明生产动效性能合格。

Harness 页面按定义、可复制表达、双轨演示、使用边界和关联阅读组织；仍遵守 VBP-002 的 Agent Harness 英文主标题、智能体运行框架中文副标题及四步双轨内容约束。设计消费原有主题体系，后续实现需兼容 VBP-003。

## 实现时的精确口径

图像用于确认布局和气质，不能直接作为逐字正文或精确 CSS 尺寸：页面设计以约 1440px 桌面宽度为目标，图像生成的实际输出分别为 1564×1006 与 1355×1161（包含标注栏）。布局实现应按实际浏览器视口重新排版，不拉伸整图。

图像中的以下细节已经在自检中识别，正式实现以本记录为准：

- 已否定的首页 R1 页脚出现的使用条款和隐私政策入口不在本轮范围，不据此创建新页面。当前 R2 已移除。
- Harness 的模型图标沿用了旧稿的厂商品牌，正式演示改用中性的“同一模型”标识，避免将通用概念限定到某厂商。
- Harness 标注 01 在导航与标题旁重复，实际标注只保留标题区域的一处。
- Harness 首页星点、聚焦摘要和完整词条入口应直接复用现有 HomeDomains 与 RouteMeteorProvider，避免按生成图另造选中状态。保留现有焦点落点和时序；新增内容接入后再回归验证。
- “来源与概念边界在正式内容中逐项核对”是原型说明，正式页应替换为经核对的真实来源。
- 颜色、字号、焦点、键盘、减少动态效果及演示行为必须在 HTML/React 阶段验证，本轮不宣称通过功能测试或无障碍验收。
