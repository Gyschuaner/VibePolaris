# BUG-6914A2D5：恢复 Harness 星星与流星切换

关联 VBP-004。用户反馈标题星星和首页进入词条的衔接效果丢失。

## 原因与修复

- `9f36738` 的六步演示改版移除了原标题星星。恢复品牌蒙版星星并提供 `data-route-star-target`，保留正文和六步演示。
- 流星仍使用旧版词条坐标。目标页面出现后，从布局尺寸计算实际星星中心，排除入场缩放的影响；沿用原时长、曲线和拖尾素材。
- 流星的 `contain: paint` 裁掉了越出 48px 容器的拖尾。保留布局隔离，移除绘制裁剪。

## 实际验证

- 独立修复工作区从 dev 创建，快进至已同步的 main `596d7e1`；未纳入主工作区已有内容重构。
- 最终 `npm run build` 通过：TypeScript、313 个静态页面。
- 1280px 桌面真实浏览器：选择 Harness、进入详情、逐帧查看轨迹与完整拖尾，结束后星星显示且路由回到 idle。飞行终点 (107,169)，最终星星中心约 (107.33,169.06)，误差小于 1px；页面无横向溢出。
- 同样从首页进入 MCP，终点 (188,186)，完成后标题和星星正常、路由回到 idle。
- 浏览器控制台未记录 error/warn。证据见截图和两个 flight JSON。
- 本轮没有追加全量测试、手机端、暗色或减少动态效果回归。六步演示内容和状态逻辑未修改。
