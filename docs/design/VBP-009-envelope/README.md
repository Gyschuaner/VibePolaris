# VBP-009 连续包络线方向稿

用户原话：「不是要很多的圈圈分别触发，而是会有一个连续的包络线」。先交付三方向可拖动设计稿，用户随后选择 A，确认记录见 [direction-approved.md](direction-approved.md)。

设计假设：光标像手指划过水面，按下处和经过的轨迹共同形成一块连续水痕。边缘是一条融合的轮廓，相交时不出现内部圆环；转弯跟着手势弯曲，旧轨迹逐渐收细。松开后保留当前整体形状，向外舒展并淡出。沿用主站雾蓝纸面、陶土主题色和系统中文字体，不需要图片素材，也不增加库。

三个方向保持相同试验区域：A「水面包络」强调宽而柔的水痕，作为推荐方向；B「轻细水线」更窄、更快消散，适合阅读界面；C「柔软拖尾」停留更久，尾部更明显。差异只在需要用户判断的动效，不重新设计网站布局。原型提供实拖和一段相同的示范轨迹，支持定格对照轮廓；示范不循环。

实现草稿：轨迹点只参与生成一个合并的透明遮罩；先融合遮罩，再从整体边界取轮廓，内部不描画圆环。空闲时不持续运行帧循环。本轮先评估形态，正式接入时还需评估全屏滤镜性能、正文选择、原生输入和 reduced-motion 避让。

## BUG-E22F9DCB：选字时保留水波，区分反馈主次

用户反馈水痕、蓝色选区和划线工具条同时出现很乱，并明确补充「选字我感觉也要有水波」。按此澄清保留水波，形成有效文字选区后将水痕降至常规强度的28%，隐藏光晕；该手势内保持淡水痕，松开后正常消散。只包含空格或换行的选区不触发弱化，空白处下次拖动恢复常规强度。

标注工具条在鼠标按住时隐藏，松开后再读取选区显示。键盘调整选区沿用原方式；工具条点击保留原生选择并避开全局水痕。没有修改笔记存储或原生选区样式。
