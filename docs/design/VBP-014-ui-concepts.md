## 机制差异与场景契约

| 页面 | 读者要学会 | 首图 / 主交互 | 正文编排 |
| --- | --- | --- | --- |
| component | 分清公共定义、不同输入和独立实例 | 一份定义展开成三张卡片；模拟在共同定义增减角色行，三个实例一起更新；分别关注，状态不串联；重置恢复 | 实物与代码并排，组合树，边界讨论 |
| props | 找到输入来源，以及操作交回谁处理 | 标签和样式配置形成按钮；读者修改值、禁用按钮、点击触发父级计数；重置清空计数 | 配置台、简短调用代码、输入与回调的解释 |
| state | 状态决定此刻可做的操作与显示结果 | 编辑草稿，发起保存，手动提供成功/失败响应；等待时锁定表单，无提前结果；失败可重试；编辑使旧结果失效 | 可操作表单与回执，事件/状态对应，快照与派生数据 |
