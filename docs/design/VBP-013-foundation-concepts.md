# VBP-013 · 第 001 批：大模型、Token、智能体

所属总需求 VBP-012。本批只更新 llm、token、agent 三个既有页面，不新增概念数量。全站覆盖见 [索引](concept-rollout.md)。

## 设计判断

| 页面 | 读完要能判断什么 | 首图 | 主交互 | 正文节奏 |
| --- | --- | --- | --- | --- |
| 大模型 | 续写、训练和事实依据的区别 | 候选条长出后，片段进入句子 | 用户选择分叉，前文和下一组候选随之改变；可撤回 | 句子工作台、训练/使用对照、重点引文、结果证据 |
| Token | 单位取决于词表，编号不是词义 | 两块排字落位，显露编号 | 字符/子词对照，文字翻面为 ID，按词表还原 | 编号实例、两项定义、解码解释、实际预算 |
| 智能体 | 行动由目标和环境反馈共同决定 | 日历交集与邀请草稿 | 双人日历由未知变可读；有空档准备草稿，无空档询问并停止 | 任务委托、日历、角色分工、工作流边界、完成证据 |

共用文章、目录、术语卡片、书目和局部星图。主交互均手动推进，没有新增定时器或持续帧循环；首图复用有限播放、离屏和后台暂停能力。用已有 States / Reveal 保留切换前后两层，隐藏层 inert，翻牌有减少动态的直接切换。

## 资料与论断

2026-09-21 实际打开以下原始资料。URL、出版者及正文锚点存于 `lib/foundation-concept-sources.ts`。

- Hugging Face LLM Course 的 Transformers、Inference：训练/推理区别、下一 Token、解码、停止条件。只采用自回归生成的适用论断，不把课程中的概略复杂度或模型规格写成通用结论。
- Google Machine Learning Crash Course 的 LLMs 页面：幻觉、错误与偏见。流畅度不是事实证据。
- Hugging Face Tokenizers / BPE：切分、ID 映射、解码、词表及合并规则。演示是人工定义的两个小词表，不伪称任何现有 tokenizer，也不在 Token 页展开完整 BPE 训练。
- Claude Token counting：输入计数含请求结构、结果为估计。保留厂商范围，不提供价格或通用“每字几个 Token”的结论。
- Hugging Face Agents Course：目标、模型和可用能力。Anthropic Building effective agents：工作流与动态选择、环境反馈、停止条件。区分术语使用范围；教学分支不是一个真实模型 Agent。

自有案例：The sky is 的候选百分比；lower / lowest 的两个词表；09:00–11:00 的两人日历及草稿。所有示例在正文中说明，未接外部模型、日历或真实发送。
