# 首页概念聚焦 R4.5 验收记录

本轮用两段式概念聚焦取代中心与轨道节点的位置交换：第一次点击放大目标概念，中心主题退场，其他节点向外围淡化，并展示一句摘要；第二次点击目标或箭头进入独立详情页。

## 文件

- `01-current.png`：改动前的星图总览。
- `02-focused-desktop.jpg`：首轮聚焦态，暴露焦点轮廓过重和中心文字叠加问题。
- `03-focused-desktop-final.jpg`：移除卡片感轮廓并隐藏背景主题后的聚焦态。
- `04-final-focus.jpg`：以“工具调用”验证最终聚焦状态。
- `05-before-after.png`：改动前后同尺寸对照。
- `06-mobile-focus.jpg`：390×844 内嵌视口的聚焦态与无横向溢出测量。

## 验证结论

- 首次点击只聚焦，不触发路由。
- 点击另一概念会直接切换聚焦对象；Escape 返回领域总览。
- 第二次点击聚焦概念或箭头触发跨页流星并到达独立术语详情。
- 首页 35 个概念全部对应真实静态详情页，不再使用可能为空的搜索结果兜底。
- 390×844 审计视口的 `scrollWidth` 与 `clientWidth` 均为 375px，无横向溢出。
- ESLint、TypeScript、13 项 Node 测试与 Next.js 生产构建通过，共生成 48 个静态页面。
