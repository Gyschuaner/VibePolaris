# VBP-055 前端基础与技术栈词条机制差异表

本批次逐条更新十个已有词条，先固定每页要让读者观察的因果链，避免只替换名词后复用同一种演示。

| 词条 | 读者要判断的问题 | 核心条件变化 | 可观察结果 | 与相邻词条的边界 |
| --- | --- | --- | --- | --- |
| responsive | 变窄时何时换列，怎样保留可读性 | 内容容器可用空间 | 列数、操作区和阅读顺序重排 | 讲布局适应，不把 CSS 属性或设备型号当机制 |
| css | 一条声明为什么赢，结果怎样进入布局 | 选择器、层叠和容器条件 | 计算值与最终排列变化 | 讲呈现规则，不处理业务数据或权限 |
| form | 输入错误时怎样反馈并安全提交 | 约束、错误状态和提交边界 | 保留有效输入，阻止或发出请求 | 讲输入契约，不把前端校验当服务端信任 |
| html | 语义元素怎样改变浏览器理解 | 元素与属性的语义 | DOM、可访问性和原生操作识别 | 讲结构和语义，不代替 CSS 或脚本行为 |
| javascript | 点击后数据和页面怎样依次变化 | 事件、状态、异步结果 | 处理函数运行，节点内容更新 | 讲语言与运行时能力，不把 DOM/API 当语言本身 |
| dom | 源文档怎样变成脚本可操作对象 | 解析、查询和内存节点修改 | 当前页面变化，源文件不回写 | 讲文档对象接口，不等同 HTML 源码 |
| framework | 谁控制应用结构和运行流程 | 框架约定与库调用方向 | 路由、生命周期和导入边界变化 | 讲控制权与升级面，不给名称划绝对界线 |
| ssg-ssr | 页面在什么时间生成、能否复用 | 构建时与请求时的数据条件 | 静态文件复用或请求生成个性化 HTML | 讲渲染时机，不把水合误当生成方式 |
| deploy | 一版代码怎样成为可验证的线上服务 | 提交、制品、环境和流量阶段 | 健康检查后切流，异常可回滚 | 讲发布链路，不把上传成功当用户可用 |
| library | 新依赖是否值得长期维护 | 原生能力、功能缺口和依赖成本 | 方案、包体积与维护范围比较 | 讲按需调用的能力，不把库和框架混成一类 |

资料与正文按词条分别记录；本矩阵只约束演示差异，不替代各页定义、边界和来源。
