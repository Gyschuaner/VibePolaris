## 机制与场景契约

| 词条 | 首图 | 主体操作及证据 | 正文组织 |
| --- | --- | --- | --- |
| 请求 | 方法、URL、body 分层合拢 | 编辑书名/方法/body，用原生 Request 构造并读取；GET 携带 body 抛错，编辑使旧结果失效；不发送网络 | 从完整消息到组装台，再拆 query/body、构造/发送/完成 |
| 响应 | 201 回执投影成书签 | 本地构造 Response，按 201/204/422 分别显示资源、删除结果、字段错误；204 跳过 JSON | 请求结果与界面对照、实验、无内容与解析边界 |
| HTTP 方法 | POST 从一张便笺增加到三张 | 同一资源集合重复 GET/PUT/POST/DELETE，真实本地状态变化；重复 DELETE 可不同响应，资源仍不存在 | 资源编辑台为主，安全/幂等双栏，方法差异短词典 |
| 状态码 | 202 大字与停在一部分的进度 | 输入数量、服务可用性决定 202/422/503；手动完成后台，再查询才得到 done，200 pending 不显示文件 | 五类简表、导出任务、错误处理、HTTP 与业务状态 |
| 请求头 | 两种表示被 Accept 筛选 | JSON/TXT 可协商、XML 得406；更改偏好隐藏旧结果，规范化 Headers | 元信息、双格式挑选、Accept/Content-Type 对照、浏览器边界 |

所有实验为本地教学对象；请求/响应使用原生对象，方法、任务、协商采用明确限定的模拟规则。没有真实写接口，没有随机耗时，核心结果由操作和状态决定。复用 States/Reveal 的持久层，隐藏层 inert；首图有限 CSS 动画复用 ConceptHero 的可见性暂停及重播。

## 已读原始资料（2026-09-21）

- MDN HTTP messages：消息组成、HTTP/1.1 可读表示与后续版本语义。其正文有关 201 无 body 的概括不采用，以专门的 201 文档及规范为准。
- MDN Request()/RequestInit、Response()：浏览器对象构造与内容类型。
- MDN HTTP methods、Idempotent；RFC 9110 §9.2：GET/PUT/POST/DELETE 与安全、幂等的边界。
- MDN HTTP status、201、204、202、422、503：类别、创建、无内容、接受而未完成、输入错误、暂时不可用。
- MDN HTTP headers、Accept、Content-Type、Content negotiation、Forbidden request header：字段名、偏好与实际类型、Vary、浏览器保留控制的字段。

规范及 MDN 的精确 URL 与正文稳定段落 ID 写在 lib/http-concept-sources.ts；无法确认发布日期的项不填日期。本站书店/便笺/导出例子为原创教学简化，不冒充资料中的真实接口。
