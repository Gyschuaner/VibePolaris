# VBP-020 本地笔记主代码接入

2026-09-21，用户确认将页边批注原型接入主代码库。覆盖所有已发布词条与 HTML、CSS、JavaScript 教程，导航提供统一“我的笔记”入口。正式站点不预置示例内容，沿用站点主题。

## 行为与数据

- 选中同一段正文中的文字后划线或写笔记；富文本、内联术语和换行保留可读摘录，不收集隐藏的术语解释与引用序号。暂不支持跨段选择。
- 桌面批注首行对应选文首行；相邻批注按原文位置排序并避让。虚线从高亮选文首行的末端连到对应笔记正文首行，两端以小圆点标记；选文在行中结束时，从文字下缘绕出，避免穿过后续文字。移动端为底部面板。
- 图标位于原“我的想法”标题位置。笔记卡片不显示常规保存状态；更新时间为 24 小时制时分，悬停或聚焦后在时间左侧显示完整日期。保存失败显示重试并保留草稿。
- 原生 IndexedDB `vibepolaris-reading-notes` 保存内容、文章路径和文字锚点，不调用服务端笔记接口。450ms 延迟保存，失焦时立即提交；未保存内容关闭页面时提示。多标签用 BroadcastChannel 通知重新读取，通知不携带笔记正文。
- 通过段落标识、摘录和前后文恢复位置。原文移动可重新匹配；歧义或删除时保留摘录并提示，不猜测位置。
- 全局笔记库支持搜索、独立随手记、删除撤销、返回原文、JSON 导出及合并导入。导入校验版本、结构、条数、大小和本站文章路径，重复内容跳过，同 ID 不同内容另存，不覆盖原笔记。
- 原型备份可导入。不同域名/端口/浏览器之间不自动迁移；清除站点数据会丢失笔记，换环境前导出备份。

## 实现

`NotesProvider` 管理全站本地数据和笔记库；`ReadingNotes` 将文章与现有目录组合成批注侧栏。CSS Custom Highlight API 高亮原文，不改写正文 DOM；不支持此 API 的浏览器仍可通过批注侧栏与笔记库访问笔记。锚点和备份逻辑位于 `lib/reading-note-anchors.ts`、`lib/reading-notes.ts`，IndexedDB 访问位于 `lib/reading-notes-storage.ts`。无新增依赖。

手机面板通过 React portal 挂到 body，避免教程正文的入场动画 transform 改变 fixed 的定位范围。对应 BUG-B7E96257 已修复并通过移动端回归。

后续按用户反馈将栏间短线改成完整 SVG 虚线连接。起点根据原文 Range 的首行合并矩形计算，终点取笔记正文位置；内容编辑、相邻避让、窗口缩放和正文变动后重新测量。SVG 不接收鼠标事件，移动端与打印隐藏。桌面 1440px/1180px 实测连接正确，编辑变长后避让仍连接对应内容，目录模式无残留线；390px 面板可用且无横向溢出。未扩大其他功能回归。
