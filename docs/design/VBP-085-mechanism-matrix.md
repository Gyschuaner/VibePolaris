# VBP-085 首图机制差异表

这十页共享阅读框架和暂停、重播、离屏暂停能力；首图只共享纸面容器，不共享同一套流程动画。每一页都把概念里的对象、动作和可观察结果画成不同的物理关系。

| 词条 | 演示对象 | 关键动作 | 结束时能看见的证据 |
| --- | --- | --- | --- |
| 权限边界 | 带 `read:sales` 的令牌、授权闸门、销售表和工资表 | 销售请求穿过闸门；工资请求在缺少 scope 的锁前退回 | 销售表打开，工资表仍锁住；交互演示保留两次审计记录 |
| XSS | 同一段字符串、HTML 解析器、文字容器、事件节点 | 字符串分别落进 `innerHTML` 与 `textContent` | 一条变成节点并出现事件入口，一条保留字面字符 |
| Skill | 任务卡、技能目录的三层抽屉 | 先扫元数据，再展开说明，最后取一个资源结果 | 上下文只留下当前步骤需要的材料 |
| 评测运行 | 带条件标签的运行账本、逐项轨迹、封存章 | 轨迹逐条盖章后才允许汇总 | 编号、条件、逐题证据和汇总锁在一册 |
| 安全评测 | 请求、工具插座、资源状态、隔离盾 | 正常请求接通；越权在盾前停下；泄露路径被切断 | 回答状态与工具副作用分开可见 |
| 成本评测 | 两个方案的令牌硬币、质量砝码、预算槽 | 硬币投入预算槽，质量砝码单独落秤 | 费用与质量并排，超预算不会被质量分数覆盖 |
| 延迟评测 | 首字光点、工具等待沙漏、完成闸、长尾样本 | 光点按时间戳前进，工具段停留更久 | 首字、工具段、完成和 p95 尾部各有位置 |
| 通过失败评分器 | 三张有不同字段的证据票、检查台、三只结果盒 | 检查台逐项读取票据并按证据落盒 | `pass`、`fail`、`unscored` 各自对应一条证据 |
| 评分规则 | 一条回答、三把不同刻度的尺、缺口夹 | 规则尺逐项比对回答 | 缺失条件停在缺口，分数能回到具体维度 |
| 人工评分器 | 两把独立刻度尺、遮挡板、校准样例 | 评审先独立落点，再打开遮挡板讨论 | 分歧和理由一起留下，不能被简单平均抹平 |

每条首图都采用有限时长的进入、操作、稳定状态；减少动态时直接呈现最后状态。互动演示中的按钮改变真实的当前状态，历史审计或证据记录只在明确重置时清空。
