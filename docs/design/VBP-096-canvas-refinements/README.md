# VBP-096 画布分栏与连线调整

根据用户对 VBP-095 的实际浏览器反馈实施，关联 BUG-07337509（文字背景截断关系线）。本轮没有重新选择设计方向，继续使用已确认的第二版画布和现有主题。

编辑页复用阅读模式的 Markdown 渲染，左侧原文、右侧实时预览。原生 Pointer Capture 实现分隔条，25%–75% 范围内拖动；方向键每次调整 5%，Home/End 到两端，双击恢复均分。两栏独立滚动；600px 以下改为上下分栏，同一分隔条调整高度。保存、导入、导出、复制和本地数据库结构沿用 VBP-095。

连线通过 ResizeObserver 获取文字按钮实际边界，保留圆点端点。原曲线没有碰到文字时直接使用；发生碰撞时，以文字外 10px 的矩形角点计算最短可见路径，并使用小圆角连接。节点拖动、内容换行、选中后收起简述都会更新路径；平移缩放继续统一变换世界坐标。用户将节点文字互相重叠并盖住圆点时，该端点处仍以文字可读为先，移开重叠节点后恢复完整避让；不自动改动用户布局。
