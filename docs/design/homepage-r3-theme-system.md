# VibePolaris 首页 R3 与主题配色系统

## 设计结论

首页采用「苔藓编辑」作为默认品牌基调：暖骨白背景、森林墨色正文、苔藓绿交互色，以及偏黄绿的北极星高光。它保留 VibeHub 式的编辑排版、发丝分隔线和低噪声信息密度，但使用 VibePolaris 自有的流星轨迹、技术领域展开结构和双层品牌配色，避免形成视觉复刻。

首页首屏只展示品牌 `VibePolaris`、副标题和一句短说明；搜索保留在导航。主体按技术领域横向陈列，领域数量可以增减，默认展开一个领域。点击其他领域后，展开内容、`aria-expanded` 与可见详情同步切换，并始终只保留一个展开状态。

## 品牌标识与动效

品牌标识由两张带透明通道的真实图片资产组成：流星轨迹与四角北极星。它们通过 CSS mask 着色，因此轨迹色和星体色可以独立响应主题配色。轨迹保持弯曲和方向连续，星体相对更大，并用更明亮的黄绿色与苔藓绿轨迹形成区分。

首次进入首页时播放一次 580ms 的抵达动画。轨迹不是整张图平移淡入，而是从原始 PNG 的 alpha 通道提取中心线，按等弧长生成 32 张累积绘制帧；星体使用 9 个等弧长锚点和单一线性时间轴连续插值，因此不会在中间帧重复减速。星体缩放沿同一时间轴从 22% 连续增长到 100%，让“小星逐渐抵达并成为北极星”的过程清晰可见。导航品牌在鼠标悬停或键盘聚焦时只做 360ms 原地轻闪，不把星体瞬移回轨迹起点。首页标识槽位为 118×104，星体图层为 48×48；星体蒙版补偿透明素材边缘，最终锚点相对最初位置向左移动 10px，导航与移动端同比例调整。系统开启“减少动态效果”时，标识保持静态完整呈现。

## 主题令牌

明暗模式与品牌配色分层保存：`vp-theme` 只保存 `light` 或 `dark`，`vp-palette` 保存品牌配色名。页面在 CSS 加载前读取两者，避免首屏闪色；未知配色自动回退到 `moss`。

当前内置三套配色：

| 标识 | 中文名 | 视觉倾向 | 计划用途 |
| --- | --- | --- | --- |
| `moss` | 苔藓编辑 | 稳重、自然、编辑感 | 当前默认 |
| `sprout` | 嫩芽墨色 | 更清新、更明亮 | 后续用户可选 |
| `pomelo` | 柚皮橄榄 | 更温暖、偏黄绿 | 后续用户可选 |

主题令牌集中在 `prototype/assets/style.css`，业务组件只消费语义变量，例如 `--bg`、`--ink`、`--accent`、`--brand-trail`、`--brand-star`。新增配色时只需要添加同名 `data-palette` 令牌组，并在 `window.VP_THEME.palettes` 注册，不应在组件里增加硬编码颜色。

## 对外接口

原型提供 `window.VP_THEME.getPalette()` 和 `window.VP_THEME.setPalette(name)`。未来接入设置面板时，选择器只调用该接口，不直接写 DOM 或 localStorage；这样主题入口可以放在设置页、导航菜单或首次偏好引导中，而不影响现有页面结构。

## 验收重点

- 1536px、900px、390px 三档宽度无横向溢出，技术领域可从横排自然重排为双列和单列。
- 点击任一技术领域后只有一个领域处于展开状态。
- 明暗模式刷新后保持，品牌配色存在安全回退且可独立持久化。
- 流星标识在正常动效与减少动态效果两种系统偏好下都可识别。
- 全站不引入运行时 AI、第三方前端依赖或用户追踪代码。
