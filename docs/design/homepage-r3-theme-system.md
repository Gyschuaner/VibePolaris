# VibePolaris 首页 R3 与主题配色系统

## 设计结论

首页采用「苔藓编辑」作为默认品牌基调：暖骨白背景、森林墨色正文、苔藓绿交互色，以及偏黄绿的北极星高光。它保留 VibeHub 式的编辑排版、发丝分隔线和低噪声信息密度，但使用 VibePolaris 自有的流星轨迹、技术领域展开结构和双层品牌配色，避免形成视觉复刻。

首页首屏只展示品牌 `VibePolaris`，搜索保留在导航。主体按技术领域横向陈列，领域数量可以增减，默认展开一个领域。点击其他领域后，展开内容、`aria-expanded` 与可见详情同步切换，并始终只保留一个展开状态。

## 首页降噪

首页信息只保留三层：品牌识别、技术领域、进入路径。导航品牌副名、Hero 副标题与口号、领域辅助说明和“精选 01”类编号移除；领域标题与一句短描述保留，不破坏扫读和专业感。

每个领域底部入口视觉上只显示向右箭头，点击范围为 44×44px，链接使用 `aria-label` 保留完整“进入对应领域章节”语义。动画只服务于领域状态变化和方向提示：桌面列宽用 420ms 平滑切换，旧详情以 140ms 淡出上移，新详情延迟 80ms 后以 240ms 淡入归位；入口箭头只在悬停或键盘聚焦时右移 5px。内容显隐只使用 `opacity` 与 `transform`，并继续支持 `prefers-reduced-motion`，不增加持续性装饰运动。

术语体系不设置“起步 / 进阶 / 熟练”阶段。术语浏览页移除阶段筛选和条目阶段标签，详情页移除阶段徽标与路线条；信息层级只保留分类、术语内容与关联概念，避免引入需要额外解释的主观分级。

## 品牌标识与动效

品牌标识由两张带透明通道的真实图片资产组成：流星轨迹与四角北极星。它们通过 CSS mask 着色，因此轨迹色和星体色可以独立响应主题配色。轨迹保持弯曲和方向连续，星体相对更大，并用更明亮的黄绿色与苔藓绿轨迹形成区分。

首次进入首页时播放一次 580ms 的抵达动画。轨迹不是整张图平移淡入，而是从原始 PNG 的 alpha 通道提取中心线，按等弧长生成 32 张累积绘制帧；星体使用 9 个等弧长锚点和单一线性时间轴连续插值，因此不会在中间帧重复减速。星体缩放沿同一时间轴从 22% 连续增长到 100%，透明度按 0%、8%、22%、42%、64%、82%、94%、98.5%、100% 逐步显现，让“小星逐渐抵达并成为北极星”的过程清晰且柔和。导航品牌在鼠标悬停或键盘聚焦时只做 360ms 原地轻闪，不把星体瞬移回轨迹起点。首页标识槽位为 118×104，星体图层为 48×48；星体蒙版补偿透明素材边缘，最终锚点在上一版基础上再向左移动 10px，即相对最初位置累计向左移动 20px，导航与移动端同比例调整。系统开启“减少动态效果”时，标识保持静态完整呈现。

## 主题画板与令牌（VBP-003）

导航右侧的调色盘入口打开一个轻量主题画板。画板只保留两条离散色带与昼夜切换：背景和主题色分别有五档，选中位置由「三角指针 + 穿过色带的针线 + 下方短刻度」共同标记。指针颜色从当前选项的配色派生，因此切换背景或主题色时会同步变化，而不是使用固定黑色。

亮色背景包括 `paper`（纸白）、`oat`（燕麦）、`limestone`（石灰）、`pearl`（冷珍珠）和 `mist`（雾蓝）；主题色包括 `moss`（苔绿）、`indigo`（墨蓝）、`clay`（陶土）、`pine`（松石绿）和 `plum`（灰紫）。背景与主题色可自由组合。陶土色的非文本强调保留 `#9A6248`，文本使用更深的 `--accent-text: #8C5942`，确保在五种亮色背景上保持 WCAG AA 对比度。

夜晚模式只有一组固定配色：背景 `#191C18`、正文 `#EEEBDD`、高光 `#B6CC32`。切换到夜晚时保留原亮色选择，回到白天会恢复；在夜晚点击任一色带选项，会直接回到亮色并应用该组合。月亮和太阳以 240ms 旋转、缩放与交叉淡化完成切换，系统开启 `prefers-reduced-motion` 时立即切换。

偏好分层持久化为 `vp-theme`、`vp-background` 和 `vp-palette`，并在 CSS 加载前写入根节点，避免首屏闪色。历史 `sprout` 自动迁移到 `pine`，`pomelo` 自动迁移到 `moss`；未知值回退到 `paper + moss`。业务组件只消费 `--bg`、`--surface`、`--ink`、`--accent`、`--accent-text`、`--brand-trail` 和 `--brand-star` 等语义变量。

色带使用 `radiogroup` / `radio` 语义，并支持方向键、Home、End、Escape 与焦点恢复。桌面画板宽 352px；390px 移动端固定保留 12px 两侧安全边距，不产生横向滚动。

## 验收重点

- 1536px、900px、390px 三档宽度无横向溢出，技术领域可从横排自然重排为双列和单列。
- 点击任一技术领域后只有一个领域处于展开状态。
- 领域切换时列宽、详情内容和入口箭头响应连贯，连续快速点击不产生残留内容；减少动态效果时立即切换。
- 术语浏览与详情页不出现起步 / 进阶 / 熟练标签、筛选或路线条。
- 明暗模式、背景与主题色刷新后保持，历史值能安全迁移，未知值有安全回退。
- 色带指针随当前颜色变化；键盘可完整操作，移动端画板不溢出视口。
- 流星标识在正常动效与减少动态效果两种系统偏好下都可识别。
- 全站不引入运行时 AI、第三方前端依赖或用户追踪代码。

## 首页星图动效（R4.1）

星图动效继续遵守“极简、降噪”：它只解释状态变化，不让整个页面持续漂浮。点击周边概念时，当前中心星与目标概念星沿各自起止位置同时飞行并交换星位；约 210ms 时完成中心内容切换，约 470ms 时收束为稳定状态。中心标题与轨道文字只做短促的透明度和位移回弹，不使用模糊、缩放整屏或装饰性连线。

切换技术分类时，旧概念先在约 150ms 内向中心聚拢并淡出，新概念随后从中心向各自轨道位置散开，完整过程约 560ms。空闲状态只保留低频单点微光和极轻的中心亮度呼吸，且不同步成片闪烁；系统开启 `prefers-reduced-motion` 时，所有交换与聚散动画直接切换到最终状态。

实现没有使用 View Transition API。实机逐帧采样发现该方案会在文字快照上产生拉伸和焦点轮廓残影，并在连续操作时触发 `InvalidStateError`；最终改为两颗独立星体的合成层位移动画，动画期间隐藏原位置星体，结束后再恢复真实 DOM。连续快速切换会清理上一轮计时器，因此不会留下重复中心星或悬空飞行星。

验收截图位于 `docs/design/qa/homepage-motion-swap-mid.png`、`homepage-motion-focus-end.png` 和 `homepage-motion-domain-end.png`。桌面、390×844 移动端、Escape 返回、45ms 快速连续切换及减少动态效果均已验证；结束态始终只有一颗中心星，控制台无错误。

## 跨页面流星导航（R4.2）

> 本节记录的“两段式换位再跨页”方案已由 R4.3 取代。逐帧回归发现它在两段动画交接时存在约 72px 的位置跳变，峰值速度约 6006px/s，不能视为通过。

## 跨页面连续星轨（R4.3）

拥有真实详情页的概念从被点击的周边星体原位起飞，不再先进行 470ms 的中心换位。根布局中的同一个覆盖层承担完整跨页运动，页面在第 120ms 发起已预取的客户端导航；路由切换不会重建星体或重算轨迹。

轨迹使用单条三次贝塞尔 motion path，820ms 内只执行一次连续缓动。飞行期间不再读取详情页坐标并回写动画变量，避免动画在路由挂载后重新起算。首页主动预取当前技术领域已有的详情页，缩短开发环境首次访问的等待。页面退场只降至 18% 不透明度并下沉 6px，目标页用 360ms 归位；尾迹继续复用品牌 `meteor-trail-mask.png`。

详情页落点仍为桌面 54px、移动端 42px，终点按详情容器的固定几何计算。全站固定保留垂直滚动条槽位，避免首页与长详情页之间因滚动条出现而产生水平布局偏移。`prefers-reduced-motion` 下不创建飞行层，直接执行路由跳转；没有真实详情内容的概念仍使用中心聚焦。

CSS 已加入结构化术语数据并生成 `/terms/css`；组件、状态、响应式、表单、API、数据库和认证等已有详情页入口也接入同一交互。当前 in-app Browser 已完成桌面动态回归；移动端 42px 落点与 reduced-motion 分支由结构测试覆盖，但 390×844 的 R4.3 动态实机回归仍需在支持调整视口的浏览器补测。

生产构建的桌面逐帧回归共观测到 61 个实际位移帧，页面在约 148ms 切换路由，最大单帧位移 14.07px；整个过程没有旧方案的动画对象交接或 72px 瞬移。覆盖层终点与最终详情星体中心偏差为 0.13px（横向）和 0.34px（纵向），结束后飞行层为 0。验收证据位于 `docs/design/audit/cross-route-meteor-2026-08-30/`。
