## 视觉真值与实现范围

- 视觉基线：上一版 CSS 词条的纸张式四格说明区；保持暖白纸张、深绿文字、青柠强调色和现有图文比例。
- 本轮意图：移除批注与示意图之间的连接线；桌面端悬停或键盘聚焦批注时强调对应区域，触屏端点击切换强调。
- 实现页面：`/terms/css` 的「02 跟 AI 怎么说」章节。
- 对比证据：`07-comparison.jpg`，从左到右为上一版、默认无连线状态、悬停“我看到的”状态。

## 验证环境

- 桌面：1536 × 1100，生产构建本地预览。
- 手机：390 × 844，生产构建本地预览。
- 交互：真实鼠标移动、按钮点击、焦点保留、场景切换、减少动效样式。

## 五个保真面

1. 布局：默认态保持四条说明围绕图文示例的原有信息层级；移除所有连线后无穿字和越界。
2. 视觉：仅当前批注与目标使用青柠描边/浅色底，非目标降噪；“不要改的”用文字高亮与图片褪色表达约束。
3. 交互：悬停“我看到的 / 我想要的 / 不要改的 / 怎么确认”分别映射旧列表、新卡片、不可改内容和手机预览。
4. 可访问性：四条说明使用原生按钮，具有 44px 最小热区、`aria-pressed`、键盘焦点与 `aria-live` 状态；减少动效偏好下禁用过渡。
5. 响应式：移动端批注按一列排列，点击可保持选中；390px 视口无横向溢出。
