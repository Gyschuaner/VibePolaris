# VBP-092：流程式首图的概念专属重做

本批沿用 `feat/VBP-092-flow-diversity`，处理已经公开的十条 AI·Agent / 模型词条。每条首图先按概念机制定义对象、操作和可见证据，再逐条实现、提交和验收；十条完成后再统一发布。

| 词条 | 首图机制 | 关键证据 | 不是默认流程图的原因 |
| --- | --- | --- | --- |
| 少样本提示 | 校样台、标签盘、冲突票 | 参数 unchanged；冲突校样让印章停下 | 示例是本轮参照物，不是永久训练流水线 |
| 函数调用 | 请求牌、检查台、只读柜、回执卡 | call_id 配对；检查不通过时柜子不开 | 重点是执行责任与回执归属 |
| 工具选择 | 候选工具托盘、风险刻度、审批票 | 选择完成但写操作仍待审批 | 重点是候选与策略，不是工具执行路径 |
| 智能体循环 | 任务账本、外部证据、停止刻度 | 回执写回账本；达到上限后封存 | 重点是状态是否获得新证据 |
| 交接 | 责任护照、负责人卡、交接凭证 | 预算、权限和回复权随护照改变 | 重点是责任边界与最小上下文 |
| 护栏 | 请求载荷、风险扫描、政策开关 | 敏感字段被标记；命中后阻断 | 重点是检查落点与处置，不是线性通过 |
| 向量存储 | 语义投影、向量卡、元数据邻域 | 查询只高亮近邻；版本过滤独立存在 | 重点是距离、过滤与来源回查 |
| 模型路由 | 质量×费用前沿、请求特征、选择收据 | 门槛改变候选；选择理由留存 | 重点是多目标选择，不是先后步骤 |
| 提示词注入 | 权威账本、来源层级、越权裁决 | 外部文字可读但不能升级权限 | 重点是信任边界，不是输入到输出流水线 |
| 编译器 | 源代码、语法树、中间表示、运行时状态 | 有效 `add(2, 3)` 得到运行回执 5；正文另看语法、目标和运行时失败 | 重点是表示层级和错误归属 |
