# VBP-020 页边批注原型

独立设计原型，沿用第 1 张页边批注方案。桌面批注首行对齐所选原文首行，随正文滚动；相邻批注按原文顺序避让，并用细线指回出处。手机使用底部面板，独立随手记在“我的笔记”中编辑。

后续主代码实现见 [VBP-020 本地笔记](../VBP-020-local-notes/README.md)。本文保留原型阶段记录；原型与主站的数据隔离，可通过导出、导入备份迁移。

批注顶部用笔记图标代替“我的想法”，底部不显示常规保存状态。更新时间显示本地 24 小时制时分，悬停或键盘聚焦时在左侧显示完整年月日；保存失败仍提供重试。

本地预览：http://127.0.0.1:4173/

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173
npm run build
node --test tests/notes-data.test.mjs
```

## 数据与范围

- 原生 IndexedDB 保存笔记，用户无需安装数据库。数据库名为 `vibepolaris-notes-prototype-v1`，与正式网站隔离。
- 笔记、摘录、锚点、搜索及备份处理都在浏览器执行，不上传服务器。清除网站数据会删除笔记；换浏览器或端口不会自动带过去。
- 支持选文划线、引用批注、随手记、自动保存、搜索、删除撤销、JSON 导出与合并导入。预置内容明确标记“示例笔记”。
- 使用段落标识、摘录、文本偏移及前后文恢复标注；不保存屏幕像素。无法确认出处时保留摘录，在“我的笔记”提示位置变化。
- 本轮只覆盖示例文章，跨段选择暂不支持。顶部非笔记导航为原型展示。
- 未集成正式站点、未合并 dev、未部署。产品需求仍为规划中。
