# VBP-095 用户自由 Markdown 知识画布

2026-10-19。负责人及研发、SIT 验收负责人：顾毅盛。用户选定第二版设计，源图为 [source.png](source.png)。实现分支 `feat/VBP-095-free-canvas` 从 `origin/dev` 创建；用户主工作区的新闻分支和未提交文件保持原样。

## 范围

- 独立导航和 `/canvas` 自由画布；新用户为空，不预置笔记。
- 任意 Markdown 内容，可无标题；不要求关联词条。正文中的普通站内链接即可引用词条。
- 节点自由拖动，空白拖动画布；滚轮平移，Ctrl/触控板捏合和按钮缩放。圆点可拖动连线，也可点按后选择另一节点。节点可用方向键移动，连线可用键盘选择删除。
- 单击先显示正文摘录，再“打开全文”进入独立全屏阅读；切换到 textarea 编辑 Markdown 源码，自动保存，Cmd/Ctrl+S 可立即保存。
- 多文件 UTF-8 Markdown 导入、单份原文复制和下载；每份导入文件不超过 5 MB，失败不覆盖已有节点。新增节点先寻找空位。
- 日期自动记录，简述底部弱化显示，详情收在操作菜单。删除节点和连线可撤销。

## 存储与边界

复用 React、React Markdown、remark-gfm、Zod 和 Phosphor，无新增依赖或服务端数据接口。原生 IndexedDB 数据库 `vibepolaris-free-canvas` 与阅读批注分开。版本校验、事务写入与修订号避免多标签静默覆盖；损坏存储不会被空画布覆盖，保存失败仍可复制或导出当前正文。清理站点数据会删除画布；`.md` 导出不包含布局与连线，目前没有云同步、全画布备份或本地文件库绑定。

## 验收记录

构建通过：按 `package.json` 的 prebuild/build 入口依次运行新闻校验和 Next production build。当前环境没有 npm 可执行程序，使用已配置的 Node 运行同一脚本，1185 个页面生成成功，TypeScript 通过。

必要逻辑测试 `node --experimental-strip-types --test tests/canvas.test.mjs` 4/4 通过，覆盖无标题笔记、正文摘录与文件名、空位放置、连线与数据结构完整性、缩放坐标。没有扩大执行整站测试。

真实浏览器验收与对照结果、截图见根目录 [design-qa.md](../../../design-qa.md)。截图中的笔记均由验收时手动新建或导入，没有写进产品初始数据。

首轮发现 `BUG-2B62F605`：批量导入固定起点可能盖住已有笔记。已改为空位放置，回归及最终状态以 DP 为准。

刷新检查发现 `BUG-CC857464`：缩放操作使隐藏溢出容器自动滚动。改用 `overflow: clip` 后，容器不再产生第二套滚动坐标；真实浏览器确认缩放往返、刷新后六个节点坐标完全一致，连线保留，见 `persistence.json`。最终控制台 warn/error 为空；复制和下载与编辑原文逐字一致。
