## 02 · 工具调用

读者入口：“AI 说读过文件，和程序真的读到了，有什么区别？”补齐服务、日志、参数和路径的含义；读者应能判断请求正确、获准、读取成功和知道故障原因分别需要什么依据。保留现有日志场景、锚点与首图。

视觉候选：① 继续用请求卡在三个角色之间移动，强化传递但与 Harness 重复，也看不出文件何时打开；不采用。② 用接线插槽比喻参数，容易把工具定义理解成物理接头，且抢走执行重点；不采用。③ 固定请求与文件两端，文件封面在执行时展开、内容在返回时显现，缺失为空轮廓、拒绝则封面保持关闭；采用。与 Harness 的修改/检查双证据区别是“外部信息由不可见变为可用”，与上下文的材料选择区别是“先执行才能获得材料”。

场景契约：未发请求、文件关闭 → 推进生成请求、检查权限、执行、返回、模型续答 → 执行前不出现日志；成功才显露文件内容；找不到文件保留空轮廓，权限拒绝保持文件关闭且不冒充文件工具执行结果。切换条件重置所有后续状态。复用现有有限步进、键盘与离屏暂停，不引入动画依赖。
