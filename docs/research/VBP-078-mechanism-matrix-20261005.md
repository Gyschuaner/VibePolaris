# VBP-078 机制差异矩阵

这十条不是把同一张流程图换十个标题。每页先回答一个零基础读者正在遇到的具体问题，再用一个能改变结果的操作把机制显出来。

| slug | 读者遇到的任务 | 核心变化 | 专属演示 | 边界/失败 |
| --- | --- | --- | --- | --- |
| `flexbox` | 为什么一排卡片会自己挤开、换行或把按钮推到最右边 | 容器沿主轴分配剩余空间，项目按 basis、grow、shrink 和 order 参与布局 | 拖动容器宽度并切换 `grow`，卡片在同一主轴重新分配；窄到阈值后出现换行而不是硬缩文字 | Flexbox 适合一维排列；同时控制二维行列、固定轨道和跨格时应看 Grid |
| `css-grid` | 为什么仪表盘的行列能同时对齐，还能让一块卡片跨两列 | Grid 同时建立列轨道与行轨道，项目落在网格线之间，显式轨道不足时才生成隐式轨道 | 把一张告警卡从单格拖到 `span 2`，两列轨道和后续行一起重排；切换 `auto-fit` 看空列是否收拢 | Grid 的轨道分配不是 Flex 的主轴拉伸；内容溢出、隐式轨道和最小尺寸仍需单独处理 |
| `breakpoint` | 为什么网页到了某个宽度突然改成抽屉、单列或更大的字 | 断点是布局策略切换的观察阈值，条件跨过它才换一套规则 | 拖动视口尺从 767px 到 768px，侧栏从常驻变成折叠并记录命中规则；再拖回观察恢复 | 断点不是设备型号清单，也不是 JS 里到处写的 magic number；内容和交互需要共同决定阈值 |
| `media-query` | 同一个页面怎样同时照顾暗色偏好、减少动画和触控设备 | CSS 条件查询根据视口、输入能力、颜色方案和用户偏好匹配规则 | 切换 `prefers-reduced-motion` 与 `hover` 条件，动画直接变成可读状态、悬停提示变成可点控件 | Media query 是样式条件；它不会替代业务权限，也不该用来猜用户设备品牌 |
| `code-splitting` | 为什么首屏先出来，进入报表页才下载图表代码 | 打包器把模块切成可独立加载的 chunk，运行到边界时再请求对应文件 | 对比单包与路由分包的网络瀑布：首屏字节不变的情况下，点开报表才出现 chart chunk | 分包改变下载时机，不会自动解决缓存、服务端渲染或第三方库重复进入多个 chunk |
| `lazy-loading` | 图片、组件或数据为什么可以先留一个占位，靠近时才加载 | 资源的获取或渲染推迟到可见、将要使用或明确触发的时刻 | 拖动视口让三张图片进入观察区，逐张从 placeholder 变成 loaded，并显示未进入视口的请求数 | Lazy loading 是时机策略；它和代码分包、分页、预加载各自解决不同的等待问题 |
| `dockerfile` | 一串 `FROM`、`COPY`、`RUN` 怎样变成可搬运的镜像 | Dockerfile 指令按顺序生成不可变层，构建上下文与缓存命中共同决定结果 | 改动依赖清单或源码，观察哪一层失效、最终文件系统和运行容器如何重新组合 | Dockerfile 描述镜像构建，不等于运行中的容器、编排文件或生产 secret；把密钥 COPY 进去是失败分支 |
| `infrastructure-as-code` | 云资源为什么能像代码一样 review、预览差异再应用 | 声明期望资源与依赖，工具对比当前状态生成 plan，再把变化应用到环境 | 在声明里把副本从 2 改成 3，先显示 plan 再 apply；模拟 drift 时 plan 把手工改动标成差异 | IaC 不是脚本录制器；状态文件、漂移、权限、不可逆资源和 provider 版本都影响结果 |
| `cdn` | 用户离源站很远时，静态文件怎样少走几段路 | 边缘节点按缓存键保存可复用响应，命中直接返回，未命中才回源并按 TTL/失效策略更新 | 切换 cache key、TTL 和 purge：第二次请求变 hit，改版本号或 purge 后重新 miss；旁边显示 origin 次数 | CDN 缓存的是符合策略的响应，不会替应用判断权限；个性化、Cookie、失效时间会改变能否缓存 |
| `visual-regression-testing` | 页面看起来“差不多”怎样被机器发现少了 4px 或颜色变了 | 同一页面在固定视口、字体和数据下生成截图，与基线按像素/阈值比较并留下 diff | 先通过基线，再把按钮间距改 4px，diff overlay 标出具体区域；切换字体未就绪时显示不可比较 | 视觉 diff 不是可访问性、业务逻辑或跨浏览器保证；基线漂移和动态内容会造成假阳性 |
