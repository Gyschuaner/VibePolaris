# VBP-104 四边端口与连线样式

DP：VBP-104；验收发现并修复 BUG-EF4BADDC。前序 Markdown 已上线，BUG-92799E7A Mermaid 闪烁也先独立发布，随后才集成本轮连线。

## 交互

节点四边各一个连接点，悬停、键盘焦点、选中或连接期间可见，已连接的点持续显示。支持点按源端口再选择目标端口，也支持直接拖动；落到节点文字时自动选择目标侧。已有无端口连线按位置选择相向端口，节点文字位置保持原坐标。

线从所选侧的法向引出，用三次贝塞尔连接；遇到标签时沿原有避障图绕行，扩大转弯留白并使用平滑圆角，圆角若侵入文字区则缩小。标题、摘要、图片与待办计数的实测边界都参与避障。节点重叠覆盖端口时只能尽量绕开其余标签，需先移动重叠节点。

点击连线显示简洁工具条，支持起点、终点、双向、无箭头及虚实线切换；左右键切换工具条焦点，Enter/Space 选择，Escape 关闭。删除连线或节点后撤销保留原端口与样式。简述卡片按节点边界和端口触摸区域选择上下左右可容纳的位置，修复下侧端口被覆盖的问题。

## 存储与兼容

边增加可选 fromPort、toPort、direction、dashed 字段，不引入依赖。画布格式升级为3，兼容读取1/2并在后续保存时迁移。旧客户端不能读取3，避免静默剥离新字段；上线后旧页面应先保存草稿再刷新。旧修订写入仍受原有乐观锁保护。

独立箭头、线型和端口修改按字段三方合并，同一字段冲突仍生成现有冲突副本。云端租户隔离、手动/自动同步开关沿用原实现。Markdown 导入、导出及复制保持节点内容语义，没有新增整张画布导出格式。
