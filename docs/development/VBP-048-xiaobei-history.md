# VBP-048 小北多会话历史

小北右上角增加历史入口，按最近更新时间列出对话，首问前 40 个字符作为标题。新建只清空当前视图，首次发送后才创建记录；切换后可翻阅 Think、简洁工具行和正文，并继续使用该会话的模型上下文。历史分页加载，每页 30 条；已在页面中输入的草稿在切换时暂存，未发送草稿不承诺刷新恢复。

## 归属和存储

沿用邀请码，不增加账号。服务端用 `邀请码 ID + 浏览器随机凭据的哈希` 隔离历史；`vp-xiaobei-browser` 为 HttpOnly、SameSite=Strict 的一年 Cookie，HTTPS 下为 Secure。每次读历史仍须有效授权。同一浏览器重新激活同一码可找回记录；换浏览器、换码或清除该 Cookie 后不能访问原记录。同码用户只共享积分，不共享对话。前端 localStorage 仅保存上次选中的对话 ID，按服务端返回的归属标识分隔。

SQLite 新增 `conversations` 表和归属索引，兼容现有邀请码、授权和账本表。可见消息和完整模型消息分别保存，历史 API 只返回可见部分；模型系统指令、完整工具参数结果不会返回浏览器。过程结束时立即写入检查点，流式片段每 500ms 保存一次，正常结束、停止或错误时立即收尾。硬崩溃可能丢失最后 500ms 尚未落盘的片段，之前的问答仍在。

继续对话时使用持久化模型消息，更新当前系统指令，并保留原 usage 校准。窗口仍为 256K、175K 提醒，每码每日 100 积分；没有增加模型调用/工具轮数上限。标题、历史加载和恢复不调用模型。

## 中断与并发

保留现有每邀请码同时一题规则。当前回答时可以打开历史列表，停止或结束后再切换、新建。刷新后若该题仍运行，界面同步已保存内容并等待结束；不会自动重发问题或重复收费。进程硬退出时，原 120 秒租约到期后将记录标为中断；未取得结果的工具调用补入明确的失败结果，避免下一轮消息配对错误。保存按活动 Run ID 和租约校验，过期运行不能覆盖后续问题。

切换请求带前端序号，晚到响应不能覆盖更新后的会话。授权归属变化时清理当前视图；所有历史 ID 读取均校验邀请码和浏览器归属，不依赖列表隐藏或前端传入的所有者。
