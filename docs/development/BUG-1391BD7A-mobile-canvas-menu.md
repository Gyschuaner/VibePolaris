# BUG-1391BD7A 手机画布菜单遮挡

关联 VBP-117。首次生产版本 `93fe22c0` 的发布后冒烟发现：手机节点菜单按完整视口底边定位，末项落在底部导航后面，点击实际进入新闻页。原有用户节点未改动，临时验收节点通过平板菜单清理。首次生产冒烟按失败记录。

修复菜单定位与最大高度，扣除底部导航所占空间；窗口尺寸变化后重新定位。保留菜单原有键盘操作、焦点和滚动。

`npm run build` 通过。真实浏览器优化构建：390×844 下菜单底边 772px、导航顶边 780px；菜单打开时改为 360×640，菜单底边 568px、导航顶边 576px。点击删除仅移除独立临时节点，地址仍为 `/canvas`，可见撤销入口。见 [浏览器事实](BUG-1391BD7A-mobile-canvas-menu/local-browser.json)。

后续 dev 集成、生产补发与回滚事实统一记录在 [VBP-117](VBP-117-news-canvas-mobile.md)。
