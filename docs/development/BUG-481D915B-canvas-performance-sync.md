# BUG-481D915B / BUG-E42A3743：画布拖动、择边与同步传输

DP：BUG-481D915B 关联 VBP-104；BUG-E42A3743 关联 VBP-101。研发与验证负责人：顾毅盛。

## 定位与改动

- 自动择边回归来自四侧端口增强（60a4fd8b）：创建连线时把推算端口写入数据，后续布局仍优先这两个固定值。现已恢复全部已存在及新连线按实测节点边界自动择边；四侧连接点继续用于发起操作，箭头、虚线与文字避障保留。历史端口字段继续兼容往返，不修改存储格式，也不迁移用户内容。
- 节点拖动原先每次 pointermove 更新画布，反复计算长 Markdown 摘要，并修改 left/top。现在按动画帧合并节点位移，松手使用最终指针坐标并立即保存；失焦、取消及卸载也提交最后待处理位移。位置改用 transform；已明确标题和摘要的笔记跳过正文扫描，普通笔记简述不解析图片资源与待办列表。
- 用户生产画布为 14 节点、7 边，约 2.7 MB；网关记录条件修订落后时的全画布 GET 被客户端取消，上游开始返回只需约 0.06–0.13 秒。服务 healthy，磁盘剩余约 15 GB，无耗尽证据。现通过 SHA-256 内容引用复用双方已有的 16 KiB 以上字符串，减少图片与长正文重传；基线内容只在各自画布内解析，缺失引用拒绝还原。
- 完整内容仍按原格式存入 IndexedDB 与云端数据库。读取引用前保留账号授权，写入前后保留预期修订检查，三方合并逻辑不变。未带协商头的旧客户端仍走原来的完整传输。首次打开或新改的大内容仍需完整传输；摘要清单限制 64 项，超出部分回退完整正文。

## 实际验证（2026-10-27）

`npm run build` 通过，BUILD_ID `a5I9o7CZ0nxJ3Iyx6zRla`。canvas、canvas-transfer、account-sync 定向检查 16/16 通过，未运行全站检查。

约 2.6 MB 的隔离 HTTP 样本：完整读取 2,632,043 B；已有内容复用后的 GET 4,814 B、移动节点 PUT 4,767 B、写入响应 4,814 B。完整 GET/PUT、引用 GET/PUT/POST、304、过期修订 409、缺失引用 400、他人账号 404 通过；失败请求未覆盖原数据，图片长文章与独立摘要完整保留。

Chrome 对优化构建进行真实操作：

- 14 节点、7 边的合成画布中，历史 top/bottom 连接自动改为相向侧。将“事件”从 DOM 左侧移到上方，端点切换到下侧/上侧；刷新后位置、箭头及虚线保留。
- 本地移动节点时另由认证 HTTP 修改另一节点的云端摘要，再点“立即同步”，页面显示“已同步”；独立远端修改与本地最终位置同时保留。刷新后仍为 14 节点、7 边。
- 另从连接点用键盘新建一条到不同节点的连线成功，随后样本为 8 边。
- 拖动前后各一次短采样，rAF 帧间隔中位数均约 16.7 ms；p95 分别约 17.5/16.7 ms。原样本已接近 60 FPS，不能据此宣称复现或彻底消除用户现场严重低帧率，仍需上线后现场复查。测量脚本仅在本机临时夹具内，不随产品交付。
