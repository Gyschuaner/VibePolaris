# VBP-122 同类动画卡片与平移换位

2026-10-26 按用户截图修订首轮浏览方案。每个现有小分类收进一张卡片，保留原动画和纸感视觉；首轮四个用途入口及独立动画平铺由此替换。负责人顾毅盛。

## 当前行为

- 共 13 张分类卡片容纳 300 个动画。左侧显示当前大预览，右侧显示四个小预览并可继续竖向滚动；分类名移到卡片上方。移除动画卡片下方名称、分类及“移入查看动效”等提示。
- 大小预览使用相同组件、效果和静帧。点击小预览后，它与当前大预览交换槽位；旧大预览回到所点的小槽位。通过原生 Web Animations API 平移并缩放，时长 700ms；保留同一个预览节点，支持连续切换。
- 用户随后明确要求播放慢一点、悬停才播放。列表预览为原速 0.6 倍，默认静帧，全目录仅鼠标悬停或键盘聚焦的一项可播放。移开恢复静帧；离屏、后台、减少动态偏好及请求失败回退沿用共享预览实现。详情和导出保持原来的速度及控制方式。
- 右侧滚动时左侧大预览固定，交换保留内层滚动位置。搜索、类型、排序仍写入 URL；进入大预览详情再返回保留原筛选，未筛选时返回全部分类。原 6 个组件、样式和素材继续可用。
- 没有新增依赖、动画源码或外部请求来源。继续使用首轮生成的 300 张真实静帧及版本化 CSS 缓存，来源文字与许可修复保持不变。

## 实现与验证

`AnimationGroupCard` 将同一分类的所有预览保持为同一网格内的有键节点；大预览横跨网格行并 sticky，避免独立滚动容器裁切换位运动。换位前后测量预览画布，700ms 内平移缩放到新槽位；新的切换从正在显示的位置继续。活动预览状态放在目录层，使不同分类之间也最多播放一项。移动端缩小同一画布，保留右侧列表。

最终 `npm run build` 通过，Build ID `lN033H0Vx7Fs_VukeZoGO`。目录现有检查继续覆盖 300 项 CSS 作用域、来源、文字、静帧及 React/HTML 导出；新增一个小型换位检查，覆盖各分类所有可选槽位、交换还原和非法索引，两项检查通过。

真实浏览器验证了鼠标、键盘选择、连续两次换位、内部滚动、搜索排序、空结果恢复、精简详情及返回。强调分类连续切换后仍为 13 个唯一动画，内层 scrollTop 296.5 保持；最终构建在 390px 下滚到圆环第 16 项并切为大预览，仍为 16 个唯一项，左侧相对卡片偏移在滚动前后均为 13px。页面和卡片均无横向溢出。组件、样式、素材各 2 项，实际打开线性图标详情并返回。最终控制台 warn/error 为空。

最终目录初始为 13 张卡片、300 张静帧、0 个活动动画。请求观察代理只记 URL：圆环分类未悬停时动画 CSS 请求为 0，聚焦第 15 项后只请求该项 1 份 CSS，无动画详情预取。预览的速度变量为 1.6667，对应 0.6 倍速。中间交互与最终构建增量证据在 browser.json 中标明；最终构建再次复核了默认静帧、窄屏滚动和交换。
