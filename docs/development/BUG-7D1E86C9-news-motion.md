## 实现

每篇在 `content/zh/news-motion/2026-*.json` 中独立写入问题、输入对象、执行者、动作、目标、结果、必要边界和选用原因。`rationale` 只供编辑审读，服务端在传入客户端前移除。作者完整读取稿件及来源证据后决定机制，不按标题关键词、旧 variant 或哈希派发场景。

33 类连续场景按事件选用：文字带、压辊、筛网、模版、权限闸门、公告印记、回卷、收据、账簿、资源容器、读头、沙漏、天平、并行通道、单路选择、织机、折页、合奏、补丁、足迹、边界移交、接口对接、镜头、机械臂、局部画布、空间层、人工复核、声音、线路、连接桥、许可钥匙、待确认购物篮与停止后续调用的闸杆。共用插值和 SVG 基础图形，各篇的对象关系与事实边界单独创作和复审。

`NewsMotionExplainer` 统一负责播放时钟。初始显示有内容的预览；首次播放从头开始，暂停后可继续，播放中重播使用新的起点。原生 range 支持键盘与手动定位；滚出舞台、切到后台会暂停。减少动态偏好默认显示终态并禁用自动播放，仍可手动查看帧。组件按文章 slug 重建，避免跨文章沿用播放状态。

SVG 使用真实舞台宽度，桌面高度 420px，窄屏高度 560px；窄屏重排对象，主要标签保持 16px。主题继承站点现有偏好，各机制有适合内容的色调。读屏描述包含角色、对象、动作、结果和必要边界。页面没有新增网络调用或外部工具操作。

`npm run build` 的 prebuild 检查 2026 已发布新闻与设计的精确集合，并校验字段、重复 slug 及数值；缺设计时构建失败。详情页对缺设计的 2026 新闻也明确报错，避免静默回到旧编号演示。旧年份继续使用原实现。

C 的窄屏正文运动通道另检查了 30% 和 60%：源页辅助行在正文离开时退隐，目标标题放入页框底部，执行者与动作放在画布下沿，避免与同一行移动正文相碰。

取景框、权限闸门、回卷和压辊有意裁切或遮住正在移动的对象；包围盒相交本身不等于可见文字碰撞。已结合截图判断这些位置。减少动态偏好已作代码审查，本轮没有切换用户系统设置。最小手动检查：系统开启减少动态后刷新，默认停在终态、播放按钮禁用、位置滑条仍可查看指定帧。
