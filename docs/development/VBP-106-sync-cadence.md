# VBP-106 画布云同步降频

## 行为

- 停止编辑3秒后自动同步；连续编辑重新计时。只观察节点与连线的实际引用变化，本地写入后的revision变化和移动视口不重置上传计时。本地450ms保存不变。
- 登录后进入云画布、切换云画布或重新开启自动同步时核对一次；随后每30分钟在页面可见时静默检查。定时器独立于编辑，不随每次保存重建。
- 窗口聚焦与同浏览器标签通知只刷新本地缓存，不额外请求云画布。恢复联网时补同步；“立即同步”仍可随时使用。
- 静默核对不显示“同步中…”，真实待上传修改仍显示保存状态，错误保留原提示。关闭自动同步停止当前画布的后台读写；账号画布列表在进入页面和每30分钟刷新元数据。
- 沿用原ETag、版本CAS、三方合并、冲突副本和账号隔离。无依赖、接口、数据库或计费变更。
