# VBP-012：373 个词条的标题小动画

用户要求：去掉标题旁/下方的大卡片和复杂框架，每个概念用简明、可辨识的连续运动解释，不使用编号或逐步翻页。范围是 373 个公开词条的标题区，正文内已有的深入实验保留。

- DP 研发任务：`192987cf-72c9-4461-8c85-d3ffb7a823d2`；负责人顾毅盛。
- 分支：`feat/VBP-012-compact-concept-motions`，从 dev 建立，已同步基础提交 `e7c96715`。
- 设计清单：[373 条运动研究](../design/compact-concept-motions.md)。每条有显式配置，相关概念共享图形原语与运动构图，未声称 373 幅构图完全不同。
- 实现：服务端 SVG 与小型播放控件；透明背景，280×140 / 手机 240×120。一次播放后停留，可暂停/重播，离屏和后台暂停，减少动态偏好使用静态终态。删除旧 hero 入口，防止特定页面继续输出大卡片；通用页面移除旧主场景。
- 区别示例：护栏分开呈现放行与拦截；冒烟检查灯控制闸门；重排序实际交换条目；Flexbox 在一行内伸展；TCP 补传缺失段，UDP 留下缺口；数据污染用集合交集表示。

本地验证：

- 2026-10-17，随应用 Node 直接执行 package.json 的 `news:validate` 和 `next build`，均通过。当前机器未安装 npm，不把直接执行说成 npm 命令已运行。同步最新 dev 后重新完成同样构建，生成 373 个词条及 798 篇新闻。
- 构建产物逐条检查：373/373 每页恰有一个 `data-motion` 首图；373 个配置全部有 renderer，无缺漏、无重复 switch case。
- 真实 IAB：桌面 1280×900 检查护栏、冒烟测试、重排序、幻觉；手机 390×844 检查护栏、参数高效微调、Softmax。动画占用尺寸符合上述约束，所查页面均无横向溢出。
- 冒烟测试重播与暂停可用，暂停后 `data-running=false`；Softmax 滚出视口后停止。有限播放结束显示重播入口。
