## 行为与边界

- 原 `markdown` 保留为草稿，`article` 单独保存；全文的小切换可独立阅读、编辑、复制和导出。问句按内容保留或融入正文，避免重复问答和免责声明。表格、代码、Mermaid 沿用现有渲染。
- 首次整理完成后得到文章；再次整理写入 `articleProposal`，用户采用后才替换文章。取消、断线或页面离开保留已经收到的片段；未完成片段明确标记，不伪装完整文章。草稿改变后提示文章来源已更新。
- 扩展可选草稿或已保存的文章，每次建议少量笔记、链接或图片。链接、图片仅取自源文档资源或匹配的已发布站内词条；没有图片资源时使用概念笔记，可含 Mermaid。不接入额外绘图或全网搜索服务。
- 候选节点虚线显示，标注小北生成；逐个接受、舍弃，舍弃沿用删除撤销。接受后保留来源标记，Markdown 导出也保留来源。按标题/资源去重，不覆盖用户原节点。
- 三个设置独立：补全保持原默认开启；整理与扩展默认关闭。账号开关随账号恢复，游客按浏览器 Cookie 隔离。启动时及流式心跳校验授权与设置，来源只使用显式选择的正文，不使用聊天记录。
- 整理、扩展分别使用独立请求、流状态、运行锁及用量类别 `canvas_organize` / `canvas_expand`。不扣积分，仍记录真实 Token 和原价成本；取消后未知用量保留待结算，不能假填零。补全现有收费开关保持关闭。
