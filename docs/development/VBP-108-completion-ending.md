# VBP-108 小北补全自然收尾与 Markdown 表格

用户要求补全保持简短，但不必在固定字数强制切断；沿用本对话检查后上线授权。
随后追加表格编辑与渲染支持，一并纳入本轮。

## 实现与边界

- 移除 `shortCompletion` 在100个Unicode码点处裁剪、再回退到句号的处理；保留前文精确重叠去除、原缩进、换行和末尾空白整理。
- 提示词改为通常20到100字、一两句，优先写完整当前句子或语法片段，必要时可稍长。Markdown、颜色、代码和 Mermaid 续写规则保持。
- 补全生成预算384改为1024 Token，给自然收尾留空间；聊天预算不变。保留接口上限、30秒请求期限、2秒冷却、异常与取消处理，不承诺无限生成。
- 账户权限、上下文截取范围、计价单价与用量记账不变，补全扣费仍关闭。
- 现有 `remark-gfm` 已支持标准 Markdown 表格，缺少插入入口，且 CSS 的左对齐覆盖了列对齐。工具栏增加「插入表格」，生成含表头、分隔行和两行内容的三列表格，选中第一列表头方便直接修改；在选区后插入，保留已有文字及段落边界，可撤销。补充表头样式和居中/右对齐，编辑预览及全屏阅读共用现有渲染器，不增加依赖。
- 小北提示词增加表格规则：沿用列数和分隔符、补完当前行，新建表格要有表头、分隔行与空行；字面管道转义。

## 实际验证

- 表格修改后重新 `npm run build` 通过（1186页）；仅运行现有 `tests/canvas-completion.test.mjs`、`tests/markdown-editor.test.mjs`，6/6通过。更新原硬截断预期，覆盖超过100字的完整 Markdown、Unicode、重叠去除、免费计量、模型请求预算、表格插入和安全渲染。
- 真实 IAB 在独立本机优化构建3106验收，3198为临时固定响应服务，仅接受合成标题「自然收尾验收」。固定响应是117字的两句完整正文，不是真实模型质量评估。
- 快捷键请求、首次发送范围说明、117字灰字建议完整显示；接受前正文未变，Tab完整接受，Command+Z一次恢复原文。无控制台错误。
- 实际请求预算1024、关闭思考，系统提示词没有「最多100字」。模型固定用量500输入/140输出，账本仅1条 canvas_completion，charge/reserved/cost均0，按原价计算的 calculated_cost为9200百万分之一积分。
- 后续表格真实浏览器验收：选中文字后插入模板，已有文字保留、第一列表头选中，一次撤销恢复原文；三列表格在编辑预览和阅读页均显示，左右/居中对齐及加粗正确。再次使用本机固定响应服务续写一行表格，灰字完整、Tab接受后为三列完整行，控制台无错误。此时累计2条免费记账，无实际扣分；证据单独保存于 `dev-table-*`。
- 本机第一次激活受到旧验收 Cookie 与全新隔离数据库不匹配影响；使用新本机测试账户后绑定临时邀请码成功，没有修改身份验证规则或清除用户 Cookie。退出并销毁该隔离数据库前会禁用临时邀请码。
- 证据在 [VBP-108-completion-ending](VBP-108-completion-ending/)；未运行整仓check或整站回归。
