# VBP-108 小北补全自然收尾与 Markdown 表格

用户要求补全保持简短，但不必在固定字数强制切断；沿用本对话检查后上线授权。
随后追加表格编辑与渲染支持，一并纳入本轮。

## 实现与边界

- 移除 `shortCompletion` 在100个Unicode码点处裁剪、再回退到句号的处理；保留前文精确重叠去除、原缩进、换行和末尾空白整理。
- 提示词改为通常20到100字、一两句，优先写完整当前句子或语法片段，必要时可稍长。Markdown、颜色、代码和 Mermaid 续写规则保持。
- 补全生成预算384改为1024 Token，给自然收尾留空间；聊天预算不变。保留接口上限、30秒请求期限、2秒冷却、异常与取消处理，不承诺无限生成。
- 账户权限、上下文截取范围、计价单价与用量记账不变，补全扣费仍关闭。
- 现有 `remark-gfm` 已支持标准 Markdown 表格，缺少插入入口。线上发布前对照确认已有列对齐通过组件内联样式生效，本轮增加显式 align 属性的回退样式。工具栏增加「插入表格」，生成含表头、分隔行和两行内容的三列表格，选中第一列表头方便直接修改；在选区后插入，保留已有文字及段落边界，可撤销。补充表头样式和居中/右对齐，编辑预览及全屏阅读共用现有渲染器，不增加依赖。
- 小北提示词增加表格规则：沿用列数和分隔符、补完当前行，新建表格要有表头、分隔行与空行；字面管道转义。
