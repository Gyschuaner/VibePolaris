# VBP-107 节点摘要、双击全文与首次展开

## 范围与实现

- 选中节点时继续显示标题下的灰色摘要；移除选中态隐藏摘要的 CSS，避免节点尺寸和连线锚点跳动。
- 节点原生双击复用 `openNote`，直接进入 Markdown 阅读；单击简述卡片和「打开全文」保留。双击阻止冒泡，连线模式不打开全文。
- 打开全文时，先用页面栏、标题和轻量正文占位参与现有 A 展开动画；等待 View Transition 的 `finished` 后才挂载 Markdown 或编辑器。沿用 540ms 动画及已有中断保护，不用另一个固定延时猜测动画结束。
- 减少动态偏好、缺少过渡 API、直接全文 URL 沿用直接渲染。未改同步协议、存储格式、账户权限或积分设置。

对应 Bug：BUG-DBF97551（选中后摘要隐藏）、BUG-2448643D（首次正文渲染抢占过渡）。生产发布沿用本对话已经明确授予的「检查后直接上线」授权。
